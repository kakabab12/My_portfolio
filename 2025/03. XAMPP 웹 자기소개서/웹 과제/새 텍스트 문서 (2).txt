개인 홈페이지 제작





다음의 조건을 만족하는 HTML, CSS 파일을 만드시오. (항목당 1점씩)

설명: HTML 을 이용한 개인 홈페이지 첫 화면 만들기

 1. 본인 사진이 화면에 나와야 함.

 2. 테이블을 만든 후 의미 있는 개인 소개 내용이 포함되어야 함.

 3. 글씨의 색상이 2종 이상 화면에 나타나야 함

 4. 글씨의 배경 색상이 2종 이상 화면에 나타나야 함

 5. 이탤릭 폰트가 포함되어야 함

 6. 다른 크기의 글씨가 있어야 함

 7. 2종 이상의 스타일이 적용된 css 파일을 별도로 만들고 html 내에서 import 시킨 후 해당 스타일을 적용.

 8. Naver, Google 등의 검색엔진 이미지를 화면 하단에 보여주고, 클릭시 해당 검색엔진으로 이동 되어야 함.
