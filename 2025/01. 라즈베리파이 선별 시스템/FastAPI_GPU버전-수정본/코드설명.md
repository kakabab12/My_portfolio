## AI 관제 시스템 파일 구조


1. 메인 AI 관제 서버 (Main Server)
## app_ck.py

역할: 비전 객체 인식과 대형언어모델(LLM)을 결합한 스마트 관제 서버의 메인 구동 파일입니다.

특징: 가볍고 빠른 FastAPI 프레임워크를 기반으로 작동합니다. 기존 YOLO 모델을 TensorRT 엔진(best.engine)으로 변환하여 GPU 가속(FP16)을 통해 실시간 초고속 추론을 수행합니다. 특히, 구글 Gemini API가 내장되어 있어 공정의 실시간 데이터(CPU, 정상/불량 누적 개수 등)를 바탕으로 사용자의 질문에 AI가 직접 분석하고 답변을 제공하는 엔드포인트(/ask_gemini)를 포함하고 있습니다.

2. 하드웨어 제어 및 프론트엔드 (Hardware & UI)
## camera.py (하이브리드 카메라 모듈)

역할: 젯슨 환경에 최적화된 지능형 카메라 래퍼(Wrapper) 모듈입니다.

특징: Intel RealSense 카메라 연결을 우선적으로 시도하며, 라이브러리가 없거나 연결에 실패할 경우 즉각적으로 일반 USB 웹캠 모드로 자동 전환(Fallback)하는 고가용성 구조로 설계되었습니다. 백그라운드 스레드에서 프레임을 읽어와 서버 메인 로직의 부하를 최소화합니다.

## index.html (스마트 대시보드 UI)

역할: 관리자가 웹 브라우저를 통해 실시간으로 공정을 모니터링하고 시스템을 제어하는 프론트엔드 인터페이스입니다.

특징: Bootstrap 5와 Chart.js를 활용하여 실시간 카메라 스트리밍, CPU/메모리/FPS 현황, 생산량 및 불량률 차트를 직관적으로 제공합니다. 특히 우측 하단에 Gemini AI 채팅 위젯이 구현되어 있어, 작업자가 실시간 현장 데이터를 기반으로 AI와 직접 대화하며 공정 분석을 진행할 수 있습니다.

3. API 및 시스템 테스트 (Testing)
## test.py (Gemini API 통신 테스트)

역할: 구글 Gemini API의 연결 상태와 사용 가능한 모델 목록을 검증하는 단일 스크립트입니다.

특징: 환경 세팅 초기 단계에서 발급받은 API 키(AIzaSy...)가 정상적으로 작동하는지 확인하고, 사용할 수 있는 AI 모델 리스트를 윈도우 터미널 인코딩(UTF-8) 오류 없이 안전하게 출력해 줍니다.
