## 📌 폴더별 상세

### 🍓 01. 라즈베리파이 선별 시스템

```
[카메라] → YOLOv8-seg (ONNX, CPU) → 마스크 면적(크기) + 사각형 비율(불량)
                                   → 6가지 분류 → 아두이노 SORT:x → 분류기 동작
                                   → 웹 대시보드 (스트리밍 + 생산량/불량률 차트)
```

**같은 기능의 세 세대**가 남아 있어 발전 과정을 볼 수 있습니다.

| 파일 | 역할 |
|---|---|
| `app_base.py` | 초기판 — 픽셀을 **3D 물리 좌표로 변환**해 `MOVE:x,y,z` 전송 |
| `app_ck.py` | 메인 — 크기·불량으로 **6가지 분류** 후 `SORT:x` 전송 |
| **`sucess.py`** | ⭐ **최종 안정판** — 불량 기준 강화 + 무게중심 계산 + 조준 십자선 UI |

여기에 **GPU 버전**(젯슨 + FastAPI + TensorRT + Gemini 관제 챗봇)까지 함께 있습니다.

### 🕹️ 02. SW파일럿 — 웹 로봇제어 UI

`roslib.js`로 **브라우저에서 ROS 토픽을 직접 발행**하는 구조입니다.
캔버스를 클릭해 로봇 이동 경로를 지정하고, 좌표 목록을 좌측 패널에 표시합니다.
