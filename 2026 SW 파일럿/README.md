# Robotics_2026

2026 SW 파일럿 로보틱스 1팀 저장소. TurtleBot3 Burger + Jetson Orin Nano 기반 로봇 프로젝트와, 그 이전 단계의 교육 과정(리눅스/ROS 2 실습, 과제) 산출물을 함께 담고 있다.

> **실행 환경**: 이 저장소의 프로그램들은 **Ubuntu 22.04 (Jetson Orin Nano)** 환경에서 작업·실행된 것이다.

## 프로젝트 요약 (`2026 sw 파일럿 로보틱스 1팀 프로젝트/`)

- **`sw/robot/`** — 핵심 소스. 젯슨에서 카메라로 손을 인식해 로봇을 조종하는 제스처 파이프라인(`src/`), ROS 2 노드(`ros2_bridge/`), SO-101 로봇팔 예제(`so101_mediapipe_arm/`), OpenCR 펌웨어 업로드 도구(`opencr_update/`), 자이로 장갑 ESP32 펌웨어(`firmware/`), 실행 설정·지도·모델(`configs/`, `maps/`, `models/`), 실행 스크립트(`scripts/`), 단위 테스트(`tests/`), 실제 로봇 ROS 2 워크스페이스 소스 백업(`runtime_sources/`)
- **`turtlebot3_ws/`** — ROBOTIS 공식 TurtleBot3 ROS 2 패키지 + 직접 작성한 waypoint 순찰/안전정지 패키지(`turtlebot3_waypoint_patrol`)
- **`20260810/`** — 특정 시점(8/10) 로봇을 구동시킨 ROS 2 설치본(bringup) 스냅샷
- **`TurtleBot3_오류_분석_및_해결_2026-08-17/`** — 제어 컴퓨터를 Jetson으로 이전하며 겪은 오류 6가지와 해결 과정 기록
- **`led_test_ws/`** — OpenCR LED 상태 표시 노드 단독 테스트 패키지
- 그 외 날짜별 작업 기록(.md), 실행 스크립트/바로가기(.sh/.desktop), 참고 매뉴얼(PDF) 등

자세한 폴더별 설명과 실행 방법은 **[`2026 sw 파일럿 로보틱스 1팀 프로젝트/README.md`](<./2026 sw 파일럿 로보틱스 1팀 프로젝트/README.md>)** 에 정리되어 있다.
