# 2026-08-22 Wi-Fi 장갑 무선 조종 통합 작업 기록

## 완료한 내용

### 1. 장갑 ESP32는 지정 Wi-Fi만 자동 연결

- 설정 파일: `firmware/esp32_mpu6050_glove/wifi_config.h`
- 장갑은 이 파일의 SSID와 비밀번호로만 접속한다. 비밀번호는 문서에 기록하지 않는다.
- 부팅 시 예전에 저장된 AP 설정을 지우고, 자동 재접속 기능을 끈 뒤 지정한 AP로만
  재시도하도록 펌웨어를 보완했다.
- 다른 저장 Wi-Fi나 주변 Wi-Fi를 자동으로 선택하지 않는다.
- ESP32가 재부팅되면 지정 Wi-Fi에 연결한 뒤, UDP discovery로 TurtleBot 컴퓨터를
  찾아 자세 데이터를 다시 전송한다.

### 2. 무선 장갑 펌웨어 업로드

- 대상 보드: ESP32 Dev Module (`esp32:esp32:esp32`)
- 업로드 포트: `/dev/ttyUSB0` (업로드 시점의 ESP32 연결 포트)
- 빌드 결과: 프로그램 저장공간 70%, 동적 메모리 14% 사용
- 업로드 후 장갑이 Wi-Fi에서 UDP 5005 패킷을 재전송하는 것을 확인했다.

장갑을 무선으로 쓸 때는 ESP32를 보조배터리 등으로 전원 공급한다. Jetson/TurtleBot에
연결한 데이터 USB는 빼야 한다. TurtleBot 전체실행에서는 `/dev/ttyUSB0`를 LDS-03
라이다가 사용하므로, 장갑을 이 포트에 연결하면 라이다와 충돌한다.

### 3. 앞뒤 조종 방향 반전

- 이 장갑의 실제 피치 축은 기본 매핑과 반대였다.
- Wi-Fi 장갑 노드를 `--invert-pitch`로 실행하도록 전체실행에 반영했다.
- 결과: 장갑을 앞으로 기울이면 전진, 뒤로 기울이면 후진한다.

### 4. `TurtleBot3 전체 실행`에 Wi-Fi 장갑 통합

`TurtleBot3_전체실행.desktop` → `scripts/turtlebot3_전체실행.sh` →
`scripts/run_navigation_gesture_joystick.sh` 경로에 Wi-Fi 장갑 수신기를 추가했다.

전체실행 시 다음 입력이 함께 시작된다.

1. TurtleBot3/OpenCR 및 LDS-03 라이다
2. Nav2/AMCL 및 A→B→C→D→A 순찰
3. 제스처 서버와 제스처 브리지
4. Xbox 조이스틱
5. Wi-Fi 자이로 장갑
6. 속도 mux (`/cmd_vel_muxed` 단일 출력)

### 5. 장갑은 컨트롤러 모드에서만 작동

자동/Nav2 또는 제스처 모드에서 장갑이 자동 주행을 가로채지 않도록
`--controller-mode-only` 옵션을 추가했다.

| 현재 모드 | 장갑 제어권 | 동작 |
| --- | --- | --- |
| AUTO/Nav2 | 없음 | 장갑은 0 속도를 유지하고 Nav2가 주행한다. |
| 제스처 | 없음 | 장갑은 0 속도를 유지하고 제스처 입력만 사용한다. |
| 컨트롤러 | 있음 | 스틱 조작 중에는 조이스틱이 우선이다. 스틱이 중립이면 장갑으로 조종할 수 있다. |

컨트롤러 모드는 기존과 같이 카메라에서 **OK 사인**으로 켠다. 컨트롤러 모드가
꺼지면 장갑도 즉시 정지하고 제어권을 반납한다.

### 6. 중립 보정과 안전 정지

- Wi-Fi 장갑 수신 후 처음 약 2초 동안 현재 자세를 중립으로 보정한다.
- 중립 보정 중에는 장갑을 편한 중립 자세로 움직이지 않고 유지한다.
- UDP 입력이 0.35초 이상 끊기면 장갑 노드와 mux가 0 속도를 출력한다.
- 장갑의 MPU6050 I2C 읽기 오류가 발생하면 송신이 중단된다. 오류가 반복되면
  MPU6050의 3.3V, GND, SDA(GPIO21), SCL(GPIO22) 배선을 점검한다.

## 사용 순서

1. 장갑 ESP32에 보조배터리를 연결하고 데이터 USB는 분리한다.
2. LDS-03 라이다는 `/dev/ttyUSB0`에 연결한다.
3. `TurtleBot3 전체 실행` 아이콘을 실행한다.
4. 장갑이 켜진 뒤 2초 동안 중립 자세를 유지한다.
5. 컨트롤러 모드로 전환한 뒤 사용한다.
   - 스틱 조작 중: 조이스틱 우선
   - 스틱 중립: 장갑 조종 가능
6. 종료는 전체실행 터미널에서 `Ctrl+C`를 누른다.
