# SW Pilot 로보틱스 PBL

## 프로젝트 개요
SW Pilot 로보틱스 과정의 PBL(Problem-Based Learning) 문제해결 학습 저장소입니다.

## PBL 주제
**공정 간 자율 운반 로봇 프로토타입 개발**  
바닥에 그려진 검은색 선(경로)을 인식하여 자율적으로 이동하고, 이동 기록 데이터를 수집하는 라인트레이싱 운반 로봇을 개발합니다.
