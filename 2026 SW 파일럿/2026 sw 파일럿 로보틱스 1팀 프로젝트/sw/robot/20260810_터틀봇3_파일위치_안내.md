# TurtleBot3 bringup 파일 위치 안내

## 실행한 launch 파일

```text
/opt/ros/humble/share/turtlebot3_bringup/launch/robot.launch.py
```

파일 확인:

```bash
less /opt/ros/humble/share/turtlebot3_bringup/launch/robot.launch.py
```

패키지 위치 확인:

```bash
ros2 pkg prefix --share turtlebot3_bringup
```

## 현재 실행 환경

```text
TURTLEBOT3_MODEL=burger
LDS_MODEL=LDS-02
ROS_DISTRO=humble
```

## 직접 관련된 파일과 패키지

- 메인 launch: `turtlebot3_bringup/launch/robot.launch.py`
- 로봇 상태 발행 launch: `turtlebot3_bringup/launch/turtlebot3_state_publisher.launch.py`
- Burger 하드웨어 파라미터: `turtlebot3_bringup/param/humble/burger.yaml`
- 로봇 모델: `turtlebot3_description/urdf/`
- LDS-02 라이다 launch: `ld08_driver/launch/ld08.launch.py`
- OpenCR/모터 제어 노드: `turtlebot3_node` 패키지의 `turtlebot3_ros`
- 로봇 상태 발행 실행 파일: `robot_state_publisher`

## 실행 구조

```text
robot.launch.py
├── turtlebot3_state_publisher.launch.py
│   └── turtlebot3_description/urdf/turtlebot3_burger.urdf
├── ld08_driver/launch/ld08.launch.py
│   └── LDS-02 라이다 (/dev/ttyUSB0)
└── turtlebot3_node의 turtlebot3_ros
    ├── param/humble/burger.yaml
    └── OpenCR (/dev/ttyACM0)
```

## 주의 사항

`/opt/ros/humble/share/` 아래 파일은 ROS 2 Humble에 설치된 실행용 설치본이다. 직접 수정하면 패키지 업데이트 시 덮어써질 수 있으므로, 수정할 때는 TurtleBot3 소스를 별도 ROS 2 워크스페이스의 `src/`에 받아 사용하는 것이 안전하다.

제스처 인식 코드는 이 bringup 패키지에 포함된 것이 아니다. 일반적으로 별도 제스처 노드가 `/cmd_vel` 토픽을 발행하고, `robot.launch.py`가 실행한 TurtleBot3 노드가 해당 속도 명령을 받아 로봇을 움직인다. 이 묶음에는 `robot.launch.py`에서 확인 가능한 TurtleBot3 구동 관련 설치 파일을 복사해 두었다.
