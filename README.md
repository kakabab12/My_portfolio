# 이지용 — 프로젝트 포트폴리오

> **카메라로 사람의 움직임을 읽어 기계를 움직이는 일**을 주로 해 왔습니다.
> 배리어프리 키오스크 입력 장치(기업 인턴), 자율주행 로봇(팀 프로젝트),
> 스마트팩토리 비전 검사(캡스톤), 의료 AI 예측 모델(대회)까지
> **인식 → 판단 → 제어 → 화면**의 전 구간을 직접 만들어 봤습니다.

**핵심 강점** — 실제 하드웨어에서 끝까지 돌아가게 만듭니다. 개발 PC에서만 되는 코드가 아니라,
그래픽카드 없는 키오스크·젯슨 보드·라즈베리파이처럼 제약이 있는 환경에서
성능을 실측하고 문제를 잡아 **현장에 배포한 경험**이 있습니다.

### 1. 배리어프리 키오스크 입력 장치 ((주)광명테크 인턴)

> 📂 [`2026 광명테크 인턴.all/`](2026%20광명테크%20인턴.all/) · **가장 비중이 큰 프로젝트**

**무엇을 만들었나** — 동사무소·법원에 놓이는 무인 민원발급기를, 손을 쓰기 어려운
사용자도 조작할 수 있게 만드는 입력 장치입니다. **일반 웹캠 1대만** 쓰고 별도 센서가 없습니다.

| 방식 | 조작법 | 대상 |
|---|---|---|
| **헤드트래커** | 고개를 움직여 커서 이동, **입을 벌려 클릭**, 응시로도 클릭 | 손을 쓸 수 없는 사용자 |
| **손 제스처** | 손 모양(한 손가락/주먹/손바닥) + 쓸기 방향으로 10종 명령 | 일반 사용자 |

**설계에서 가장 신경 쓴 것**

- **손 모양이 계층을, 이동 방향이 기능을 정한다** — 탐색(한 손가락)은 아무리 반복해도
  화면이 안 바뀌고, 화면 전환은 주먹을 쥐어야만 실행됩니다. 오발 방지를 규칙 자체에 넣었습니다.
- **얼굴 기준 좌표계** — 커서 기준점을 화면이 아니라 *얼굴 자신*을 기준으로 재도록 재설계해서,
  자세를 고쳐 앉거나 몸이 움직여도 커서가 밀리지 않게 만들었습니다(아래 표의 "0 px").

**수치로 본 결과**

| 항목 | 이전 | 이후 |
|---|---|---|
| 배포 용량 | 8 GB | **1.1 GB** |
| 화면 1프레임 렌더링 | 19.8 ms | **10.4 ms** (−47%) |
| 몸이 움직일 때 커서 오차 | 밀려감 | **0 px** |
| 입 벌릴 때 커서 오차 | 밀려남 | **0.00 px** |
| 드래그 중 커서 떨림 | 2.05 px | **0.78 px** (−62%) |
| 카메라 고장 시 | 조용히 정지 | **4초 내 자동 복구** |
| 오류 40초치 로그량 | 약 1,200줄 | **2줄** |

### 2. TurtleBot3 자율주행 + 제스처 제어 로봇 (SW 파일럿 1팀)

> 📂 [`2026 SW 파일럿/`](2026%20SW%20파일럿/) · 팀 프로젝트 · **Ubuntu 22.04 / ROS 2 Humble / Jetson Orin Nano**

**무엇을 만들었나** — TurtleBot3를 **네 가지 방식으로 조종**하고, 지도 기반으로 **스스로 순찰**하며,
**기계 소리로 이상을 감지**해 LED로 알리는 통합 로봇 시스템입니다.

| 기능 | 구현 내용 |
|---|---|
| **손 제스처 조종** | 웹캠 → MediaPipe 손 인식 → 손끝 위치를 D-pad 방향으로 매핑 → `/cmd_vel` 발행 |
| **자이로 장갑 조종** | ESP32 + MPU6050 장갑 펌웨어를 직접 작성, Wi-Fi로 기울기 전송 |
| **조이스틱 조종** | 여러 입력 중 하나만 로봇에 전달하는 **다중화(mux) 노드** 설계 |
| **자율 순찰** | SLAM으로 공장 지도 작성 → Nav2로 A→B→C→D→A 웨이포인트 순찰 |
| **안전 로직** | 자율주행 중 장애물 감지 시 **정지 → 후진 → 재개** 상태 머신 |
| **소리 이상감지** | USB 마이크로 기어박스 소리를 듣고 SVM 모델로 이상 판정 → OpenCR LED 알림 |
| **로봇팔 연동** | SO-101 6축 로봇팔을 사람 팔 동작으로 원격조종 |

**엔지니어링 포인트**

- **하드웨어 없이도 검증되게** 만들었습니다 — 손 모양 판별, D-pad 매핑, mux 로직,
  웨이포인트 도착 판정, LED 상태 머신을 GPIO 접근부와 분리해 **단위 테스트**로 검증합니다.
- **Jetson 이전 트러블슈팅 기록** — 제어 컴퓨터를 Jetson으로 옮기며 겹쳐 터진 6가지 문제
  (rosdep 오선언, Conda/시스템 Python 충돌, 빌드 잔재, 모터 토크 비활성, 라이다 모델·포트 오류)를
  **원인 → 조사 과정 → 수정 방법** 순으로 정리해 남겼습니다.
  📖 [트러블슈팅 문서](2026%20SW%20파일럿/2026%20sw%20파일럿%20로보틱스%201팀%20프로젝트/TurtleBot3_오류_분석_및_해결_2026-08-17/README.md)
- 사전 학습 자료로 **로보틱스 기초 9편 + ROS 2 13편**을 직접 정리했습니다
  (모터·휠·센서·엔코더·차동구동·제어 / 리눅스·노드·토픽·퍼블리셔·서브스크라이버·launch).

### 3. 스마트팩토리 비전 검사 시스템 (캡스톤)

> 📂 [`2026 1학기 젯슨나노 객체인식 분류+르로봇/`](2026%201학기%20젯슨나노%20객체인식%20분류+르로봇/)

**무엇을 만들었나** — Jetson Orin Nano에서 **카메라 2대를 동시에** 돌려
박스를 분류하고 무게 숫자를 읽어, 결과를 아두이노로 보내 로봇팔을 제어하는 시스템입니다.

**하드웨어 문제를 설계로 극복한 사례**

원래 CSI 카메라(IMX219) 기반으로 GStreamer 파이프라인까지 만들어 뒀는데,
**CSI 포트가 물리적으로 고장** 났습니다. 이를 Intel RealSense + 일반 USB 웹캠 조합으로
갈아엎고 FastAPI 멀티스레딩으로 두 카메라의 YOLO 추론을 병렬 처리하도록 재설계해 전시회를 완주했습니다.
*(기존 CSI 버전 코드도 설계 변경 과정을 증명하려고 함께 보관했습니다.)*

| 항목 | 내용 |
|---|---|
| **추론 가속** | PyTorch(`.pt`) → TensorRT(`.engine`) 변환, **FP16 반정밀도**로 속도 향상 |
| **카메라 고가용성** | RealSense 우선 연결 → 실패 시 **자동으로 USB 웹캠으로 폴백** |
| **디버깅 도구** | 듀얼 카메라 멀티스레딩 안정성 점검용 진단 스크립트를 따로 제작 |
| **관제 UI** | 두 카메라 실시간 스트리밍 + CPU/FPS 모니터링 + **Gemini 챗봇으로 공정 상태 질의** |

### 4. 수술 위험도·예상시간 예측 AI (머신러닝 대회)

> 📂 [`메디컬 머신러닝 대회/`](메디컬%20머신러닝%20대회/) · 데이터셋: INSPIRE (공개 수술기간 의료 데이터)

**무엇을 만들었나** — 수술 기록·진단·검사·활력징후 데이터를 병합해
**① ICU 입원 위험도(분류)** 와 **② 수술 소요시간(회귀)** 을 동시에 예측하고,
**왜 그렇게 판단했는지 의료진에게 설명**하는 대시보드까지 만들었습니다.

| 항목 | 내용 |
|---|---|
| **데이터 누수 방지** | 수술 **전** 시점(`cutoff_time`)을 엄격히 통제해 미래 데이터 참조를 차단 |
| **모델** | LightGBM(분류+회귀) → ICU 분류는 **XGBoost로 교체한 하이브리드** 버전까지 |
| **설명가능 AI(XAI)** | SHAP으로 변수 중요도 시각화 + **개별 환자 폭포수 차트**("이 환자는 왜 오래 걸리나") |
| **임상 보정** | AI 확률값에 ASA 등급·응급 여부·혈액검사 수치를 반영해 위험도를 보정 |
| **서빙** | Flask API 서버 + 이미지 없이 **CSS/SVG만으로 만든 원형 게이지 대시보드** |

> 단순히 "위험/안전"만 알려주지 않고, **최단·최장 수술 시간**과 **결정적 요인**,
> **종합 임상 소견**까지 텍스트로 브리핑하도록 설계했습니다.

### 5. 라즈베리파이 객체인식 선별 시스템

> 📂 [`2025 2학기 라즈베리파이 객체인식 아두이노 분류 동장/`](2025%202학기%20라즈베리파이%20객체인식%20아두이노%20분류%20동장/)

라즈베리파이에서 **YOLOv8-seg(ONNX)를 CPU로** 돌려 물체의
**마스크 면적(크기)과 사각형 비율(불량 여부)** 을 계산하고, 6가지로 분류해 아두이노 분류기를 제어했습니다.

| 버전 | 환경 | 특징 |
|---|---|---|
| `app_base.py` | RPi + Flask | 픽셀 좌표를 **3D 물리 좌표로 변환**해 `MOVE:x,y,z` 전송 |
| `app_ck.py` | RPi + Flask | 크기·불량 판정 후 `SORT:x` 상태 번호 전송 |
| `sucess.py` | RPi + Flask | 불량 기준 강화 + 무게중심 계산 + 조준 십자선 UI (**최종 안정판**) |
| GPU 버전 | Jetson + FastAPI | TensorRT 가속 + **Gemini 관제 챗봇** 탑재 |

카메라는 Picamera2로 FHD·오토포커스·화이트밸런스를 하드웨어 레벨에서 초기화했고,
웹 대시보드에는 실시간 스트리밍·CPU/메모리/FPS·생산량/불량률 차트(Chart.js)를 붙였습니다.

### 6. 웹캠 하나로 로봇팔 원격조종

> 📂 [`개인 프로젝트/MediaPipe-SO-ARM101-Teleoperation/`](개인%20프로젝트/MediaPipe-SO-ARM101-Teleoperation/) ·
> [`개인 프로젝트/mediapipe 관절값으로 르로봇 제어/`](개인%20프로젝트/mediapipe%20관절값으로%20르로봇%20제어/)

**장갑도 센서도 없이 웹캠의 2D 좌표(x, y)만으로** SO-ARM-101 6축 로봇팔을 실시간 조종합니다.
사람이 팔꿈치를 90° 굽히면 **로봇도 90° 굽도록**, 각도를 1:1로 전달하는 것이 목표였습니다.

| 로봇 관절 | 사람 동작 | 계산 방식 |
|---|---|---|
| `shoulder_pan` | 팔 좌우 | 손목의 어깨 대비 x 오프셋 ÷ 위팔 길이 |
| `shoulder_lift` | 팔 위아래 | `asin((어깨y − 팔꿈치y) ÷ 위팔길이)` |
| `elbow_flex` | 팔꿈치 굽힘 | `180° − 위팔·아래팔 사잇각` |
| `wrist_flex` | 손목 꺾기 | 아래팔 벡터 대비 손바닥 벡터의 **부호 있는** 각도 |
| `gripper` | 손 펴기/주먹 | 엄지끝 ↔ 나머지 손가락끝 평균거리 ÷ 손바닥 길이 |

떨림은 **1€ Filter + SmoothDamp 2단계 필터링**으로 잡았고,
실행 중 키보드로 방향·0점·배율을 조정해 파일로 저장할 수 있게 만들었습니다.

### 8. 웹서버 + DB 연동 기초 (직접 쓴 학습 교재)

> 📂 [`웹서버 DB 연동 기초/`](웹서버%20DB%20연동%20기초/) · **15챕터 + 실습코드 3벌**

"웹 서버가 뭐고 DB가 뭔지, 왜 종류가 나뉘고 뭘 골라야 하는지"를 익히려고
**같은 방명록 앱을 한 축씩만 바꿔가며 3벌** 만들었습니다.

```
01_flask_sqlite     Flask   + SQLite    ← 기준
02_fastapi_sqlite   FastAPI + SQLite    ← 웹 서버만 교체
03_flask_mongodb    Flask   + MongoDB   ← DB만 교체
```

정적 웹 서버(Apache/Nginx/IIS) vs 프레임워크(Flask/FastAPI/Express),
관계형 DB vs NoSQL, WSGI/ASGI 구조, **파라미터 바인딩으로 SQL 인젝션 직접 막아보기**,
REST API와 HTTP 상태 코드까지 15개 챕터로 정리했습니다.
