# VR 손잡이로 PiPER 조종하기 (헤드셋은 머리에 안 씀)

> **11/18 보류.** 교수님 의견에 따라 손 키포인트(웹캠) 조종을 먼저 합니다. 이 방법은 가짜 컨트롤러 시험(`--selftest`)까지만 했고, Quest 연결과 실물 팔 시험은 하지 않았습니다.

2026-11-17 에 더했습니다. 웹캠으로 손을 재면 앞뒤·위아래가 많이 틀려서, Quest 오른손 컨트롤러만 손에 들고 조종하는 방법입니다.
컨트롤러 위치는 헤드셋 카메라가 재므로 헤드셋은 필요합니다. 머리에 쓰지 않고 옆에 세워 둡니다.

규칙은 웹캠 조종과 같습니다. **사람 쪽 종이 + 에서 컨트롤러가 움직인 만큼, 로봇 집게 끝도 로봇 쪽 종이 + 에서 똑같이 움직입니다.**
두 책상에서 각자 + 를 기준으로 같은 자리에 물체를 두면, 컨트롤러로 집는 자리에 집게도 갑니다.

## 준비물

- Quest 헤드셋, 오른손 컨트롤러
- 테이프 조금 (근접 센서 가리기)
- A4 두 장 (사람 쪽, 로봇 쪽). 가운데에 + 를 그림
- 헤드셋을 올려 둘 곳 (선반, 삼각대, 모니터 위 등. 머리 높이쯤)
- Quest 와 연구실 PC 가 같은 망 (Quest 브라우저에서 연구실 PC 주소가 열려야 함)

설치할 것은 없습니다. Node·npm 도 필요 없고, 찬혁님 piper-teleop 의 웹 앱과 서버는 쓰지 않습니다.

## 1. 종이 놓기

- 로봇 쪽: 종이 가운데 + 가 **로봇 밑동 가운데에서 앞으로 30 cm** 에 오게 놓습니다. 종이 긴 쪽이 로봇 좌우.
- 사람 쪽: 헤드셋이 내려다볼 수 있는 곳 아무 데나. 손이 편한 곳.

## 2. 연구실 PC 에서 켜기 (먼저 팔 없이)

```bash
cd ~/smolVLA/webcam_piper
~/smolVLA/chanhyuk_piper-teleop/.venv/bin/python vr_handle.py
```

터미널에 `https://주소:8443` 이 나옵니다. 처음 켜면 https 용 인증서를 스스로 만듭니다 (`vr_cert/`, GitHub 에는 안 올라감).

Quest 없이 계산만 시험하려면 `--selftest` (가짜 컨트롤러, 마지막 줄 "결과: 모두 통과 (13/13)").

## 3. Quest 준비

1. 헤드셋 안쪽, 두 렌즈 사이 위에 있는 작은 근접 센서를 테이프로 가립니다. 안 가리면 벗었을 때 잠들어서 추적이 멈춥니다.
2. Quest 브라우저에서 터미널에 나온 `https://주소:8443` 을 엽니다.
3. "연결이 비공개로 설정되어 있지 않습니다" 가 나오면 **고급 → 계속** 을 누릅니다 (이 PC 가 직접 만든 인증서라서 나오는 경고).
4. 화면에 `robot PC connected` 가 보이면 **Start (passthrough)** 를 누릅니다.
5. 헤드셋을 벗어 머리 높이쯤 선반에 올려 두고, **손이 움직일 곳을 내려다보게** 합니다. 컨트롤러 윗면이 헤드셋 쪽을 보면 잘 잡힙니다.

## 4. 기준 잡기 (새로 Start 할 때마다 한 번)

사람 쪽 종이 + 에 **컨트롤러 앞 끝**을 대고, 컨트롤러가 **로봇 앞쪽에 해당하는 방향**(종이에서 로봇 밑동 반대쪽)을 가리키게 한 채 **B 를 1초** 누릅니다.
짧게 세 번 떨리면 됐습니다. 이 순간 컨트롤러 자리 = 로봇 쪽 종이 + 의 종이 면입니다.

## 5. 움직이기

| 컨트롤러 | 하는 일 |
|---|---|
| 쥐기 버튼(가운데 손가락) 누르고 있음 | 따라감. 처음에는 팔이 천천히 다가옴 (손을 멈춰 두기). 짧게 두 번 떨리면 그때부터 손과 같은 속도 |
| 쥐기 버튼 놓음 | 그 자리에 멈춤 (처음 자세로 돌아가지 않음) |
| 방아쇠(검지) | 집게. 당길수록 닫힘 |
| 컨트롤러 돌리기 | 집게가 아래를 본 채 같은 방향으로 돎 (`--no-yaw` 면 안 돎) |
| B 1초 | 기준 다시 잡기 (쥐기 버튼을 놓은 상태에서) |
| A | 기록 시작 (한 번 떨림) / 저장 (두 번) |

길게 한 번 떨리면 멈췄다는 뜻입니다. 헤드셋이 컨트롤러를 못 봤거나, 헤드셋이 잠들었거나, 신호가 0.25초 넘게 안 왔을 때입니다.
그 이유가 터미널에 나옵니다. 다시 하려면 쥐기 버튼을 놓았다가 다시 누릅니다.

## 6. 실물 팔

CAN 은 예전처럼 칸막이 밖 터미널에서 켭니다 (`sudo ip link set can0 up type can bitrate 1000000`). 팔 둘레를 비우고 전원 옆에 사람이 있어야 합니다.

```bash
# 첫 시험: 집게가 종이보다 10 cm 떠서 따라감, 팔 속도 50%
~/smolVLA/chanhyuk_piper-teleop/.venv/bin/python vr_handle.py --robot agxbus --speed 50 --lift 0.10
```

```bash
# 잘 되면: 사람과 같은 속도 (연구실 VR 조종과 같은 100%)
~/smolVLA/chanhyuk_piper-teleop/.venv/bin/python vr_handle.py --robot agxbus --speed 100
```

시작할 때 Enter 를 받습니다. 쥐기 버튼을 누르기 전에는 팔이 움직이지 않습니다.

## 7. 끝난 뒤 숫자 보기

Ctrl+C 로 끄면 이번 기록을 바로 숫자로 보여 줍니다. 나중에 다시 보려면:

```bash
~/smolVLA/chanhyuk_piper-teleop/.venv/bin/python vr_handle.py --report data/날짜_시각/session.npz
```

- Quest 신호 초당 몇 번, 가장 긴 끊김
- 팔이 컨트롤러보다 늦은 정도 (ms)
- 빠르기: 컨트롤러 목표와 실제 집게 끝의 빠르기 비교 (%)
- 움직인 폭: 앞뒤·좌우·위아래 목표와 집게 끝 (위아래가 따라갔는지)

## 안전 제한 (옵션으로 바꿈)

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--speed` | 50 | 실물 팔 속도 % |
| `--lift` | 0 | 집게를 이만큼 띄워 따라감 (m) |
| `--min-z`, `--max-z` | 0.01, 0.35 | 집게 끝 높이 범위 (책상 위 m) |
| `--max-speed` | 1.0 | 집게 끝 최고 속도 (m/s). 넘으면 잘라서 따라감 |
| `--catchup-speed` | 0.08 | 따라가기 시작할 때 다가가는 속도 (m/s) |
| `--joint-rate` | 3.0 | 관절 최고 속도 (rad/s) |
| `--mode clutch` | paper | 종이 기준 없이, 쥐기 버튼 누른 자리에서부터 움직인 만큼 |
| `--pull-open` | 꺼짐 | 방아쇠 당기면 열림 (찬혁님 방식) |
| `--x0`, `--y0` | 0.30, 0 | 로봇 쪽 종이 + 자리 (밑동에서 앞, 왼쪽 m) |

작업 상자: 밑동에서 앞 14~50 cm, 좌우 ±25 cm (웹캠 조종과 같음).

## 안 될 때

| 터미널에 나온 말 | 할 것 |
|---|---|
| `waiting for the Quest page` | Quest 브라우저 주소 확인. 같은 망인지 (Quest 에서 주소가 안 열리면 망이 다름) |
| `page open, press Start` | Quest 화면에서 Start |
| `headset not seeing the controller` | 헤드셋 자리·각도. 컨트롤러가 헤드셋 시야 안에 있게 |
| `XR paused (headset asleep?)` | 근접 센서 테이프 확인 |
| `no reference (B 1 s)` | 4번 기준 잡기 |
| 화면에 `WebXR not available` | 주소를 https 로 열었는지 |

## 확인한 것과 아직 모르는 것 (11/17)

- 확인: 가짜 컨트롤러 시험 13개 통과 (가상 팔). 위아래 ±10 cm 를 20 cm 그대로, 늦음 25 ms, 빠르기 97%.
  추적이 끊기면 멈추고 그 자리 유지, 놓았다 누르면 다시 따라감, 방아쇠로 집게 닫힘, 종이 기준 위치 0 mm 차.
- 아직 모름: 헤드셋을 벗어 둔 채 Quest 브라우저가 계속 컨트롤러 위치를 보내는지 (메타 공식 문서에 없음, 직접 해 봐야 앎).
  실물 팔의 늦음·빠르기 (가상 팔 숫자는 실물이 아님). Quest 브라우저가 이 PC 의 자체 서명 인증서로 WebXR 을 여는지.
