# 내일 할 것들 — TurtleBot3 + 소리 이상감지 통합 시험

작성일: 2026-08-22

## 오늘 확인된 상태

- TurtleBot3 OpenCR: `/dev/ttyACM0`에서 정상 연결됨.
- LDS-03 라이다: `/dev/ttyUSB0`에서 정상 연결됨.
- 첫 통합 실행 때 TurtleBot3 노드와 라이다가 정상 기동했습니다.
- 조이스틱 `/dev/input/js0`은 연결되어 있지 않았습니다. 이제 조이스틱이 없어도
  나머지 통합 시험은 시작되며, 조이스틱 입력만 건너뜁니다.
- 소리 이상감지 노드는 상태 토픽이 15초 안에 오지 않아 안전하게 전체 실행이
  종료됐습니다. 첫 모델/오디오 라이브러리 로딩 시간을 고려해 대기 시간을 60초로
  늘렸습니다.

## 오늘 반영한 수정

- `sw/robot/ros2_bridge/sound_anomaly_with_led.launch.py`
  - 예전의 `hw:1,0` 마이크 강제값을 제거했습니다.
  - `sound_anomaly.yaml`의 마이크 설정을 그대로 사용합니다.
  - Python 의존성 경로와 즉시 출력 설정을 유지했습니다.
- `sw/robot/scripts/run_navigation_gesture_joystick.sh`
  - 소리 감지 상태(`/sound_anomaly_node/state`)를 최대 60초 기다립니다.
  - 상태가 오지 않으면 Nav2·수동 제어를 시작하지 않고 안전 종료합니다.
  - 조이스틱이 없으면 실행 전체를 막지 않고 조이스틱 노드만 생략합니다.

## 내일 실행 전 연결 확인

USB 마이크, OpenCR, 라이다를 연결하고 아래를 실행합니다.

```bash
ls -l /dev/ttyACM* /dev/ttyUSB* /dev/input/js*
arecord -l
```

기대값:

- OpenCR: `/dev/ttyACM0`
- 라이다: `/dev/ttyUSB0`
- 조이스틱(있다면): `/dev/input/js0`
- `arecord -l`에는 USB Microphone 카드가 보여야 합니다.

마이크 장치 이름도 확인합니다.

```bash
PYTHONPATH=/home/user/ros2_ws/python_deps \
  /usr/bin/python3 /home/user/ros2_ws/src/dyeun_robotics/sound_anomaly/scripts/list_audio_devices.py
```

출력 장치명이 `sound_anomaly.yaml`의 아래 값과 다르면 그 값을 바꿉니다.

```text
USB Microphone: Audio (hw:2,0)
```

설정 파일:

```text
/home/user/ros2_ws/src/dyeun_robotics/sound_anomaly/config/sound_anomaly.yaml
```

## 통합 실행 (자동 순찰 없음 — 먼저 이것으로 시험)

바퀴를 들거나 장애물이 없는 넓은 공간에서 실행합니다. 옵션을 다음 줄에 따로
입력하지 말고 **한 줄 전체를** 실행합니다.

```bash
cd /home/user/sw/robot && bash scripts/run_navigation_gesture_joystick.sh --usb-port /dev/ttyACM0
```

정상 흐름:

1. TurtleBot3/OpenCR와 라이다가 시작됩니다.
2. 소리 이상감지 상태를 최대 60초 기다립니다.
3. 상태가 오면 제스처 서버, 속도 mux, Wi-Fi 장갑, Nav2/AMCL이 시작됩니다.
4. 조이스틱이 없으면 관련 단계만 `생략`으로 표시됩니다.

이 명령은 Nav2 목표를 별도로 주기 전에는 자동 주행을 시작하지 않습니다.

## 실행 중 상태 확인용 터미널

새 터미널에서 아래를 실행합니다.

```bash
source /opt/ros/humble/setup.bash
source /home/user/turtlebot3_ws/install/setup.bash
source /home/user/ros2_ws/install/setup.bash
```

아래 중 필요한 토픽을 확인합니다.

```bash
ros2 topic echo /sound_anomaly_node/state
ros2 topic echo /sound_anomaly_node/anomaly_probability
ros2 topic echo /opencr_led_status
ros2 topic echo /cmd_vel_muxed
```

LED 기대값:

| 감지 상태 | LED |
| --- | --- |
| `IDLE` | 초록·빨강 모두 켜짐 |
| `NORMAL` | 초록 점멸 |
| `ABNORMAL` | 빨강 점멸 |

## 동작 시험 순서

1. 조용한 상태, 정상 기어 소리, 이상 소리를 각각 3초 이상 마이크에 들려서
   `IDLE → NORMAL/ABNORMAL`과 LED 변화가 맞는지 확인합니다.
2. RViz에서 AMCL 초기 위치를 지정하고 Nav2 목표를 하나 지정합니다.
3. 짧은 따봉으로 제스처 제어권을 켜고, 전진·후진·좌·우·정지 동작을 저속으로
   확인합니다.
4. Wi-Fi 장갑은 OK 사인으로 컨트롤러 모드를 켠 뒤 2초 중립 보정 후 확인합니다.
5. 조이스틱을 연결했다면 전체 실행을 종료한 뒤 다시 시작하여 `/dev/input/js0`이
   보이는 상태에서 조이스틱 동작도 확인합니다.
6. 위 항목이 모두 통과한 뒤에만 자동 순찰을 실행합니다.

자동 순찰은 실제로 A→B 이동을 시작하므로 마지막에만 실행합니다.

```bash
cd /home/user/sw/robot && bash scripts/turtlebot3_전체실행.sh --usb-port /dev/ttyACM0
```

## 소리 감지에서 다시 멈출 때

1. 통합 실행 터미널의 `sound_anomaly_node` 오류 줄 전체를 복사합니다.
2. 아래 두 출력도 같이 확인합니다.

```bash
arecord -l
PYTHONPATH=/home/user/ros2_ws/python_deps \
  /usr/bin/python3 /home/user/ros2_ws/src/dyeun_robotics/sound_anomaly/scripts/list_audio_devices.py
```

3. 마이크 카드 번호가 바뀌었다면 `sound_anomaly.yaml`의 `audio_device`를 실제
   PortAudio 장치명과 같게 바꿉니다.
4. 종료는 통합 실행 터미널에서 `Ctrl+C`를 한 번 누릅니다. 이상감지 노드가 먼저
   LED 끄기 명령을 보내고 나머지 노드를 종료하도록 되어 있습니다.
