# TurtleBot3 웨이포인트 순찰 방법

## 실행 전 준비

- 실제 로봇을 A 표시 위치에 놓는다.
- 측정 당시 방향인 `yaw: 0.003` 방향으로 맞춘다.
- 순찰 노드가 A 초기 자세를 자동 설정하므로 RViz의 `2D Pose Estimate`는 누르지 않는다.
- 조이스틱은 실행하지 않는다.
- 주행 경로에 사람이나 위험한 장애물이 없는지 확인한다.

## 터미널 1: 로봇 본체와 LDS-03

```bash
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source ~/turtlebot3_ws/install/setup.bash

export TURTLEBOT3_MODEL=burger
export LDS_MODEL=LDS-03

ros2 launch turtlebot3_bringup robot.launch.py
```

본체와 라이다가 정상적으로 올라오는지 확인한다.

## 터미널 2: Nav2와 RViz

```bash
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source ~/turtlebot3_ws/install/setup.bash

export TURTLEBOT3_MODEL=burger

ros2 launch turtlebot3_navigation2 navigation2.launch.py \
  map:=$HOME/turtlebot3_ws/maps/factory_map_20260821.yaml
```

RViz에서 지도와 라이다가 보일 때까지 기다린다. `2D Pose Estimate`와 `Nav2 Goal`은 누르지 않는다.

## 터미널 3: 위치 확인용 모니터

```bash
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source ~/turtlebot3_ws/install/setup.bash

ros2 run tf2_ros tf2_echo map base_footprint
```

순찰 시작 전에는 `map` 프레임이 없다는 대기 메시지가 나올 수 있다. 터미널 4에서 순찰 노드가 A 초기 자세를 자동 발행하면 좌표가 출력되기 시작한다.

## 터미널 4: 웨이포인트 순찰 시작

터미널 1과 2가 정상이고, 로봇이 실제 A 위치와 방향에 놓인 것을 확인한 다음 실행한다.

```bash
conda deactivate 2>/dev/null || true
source /opt/ros/humble/setup.bash
source ~/turtlebot3_ws/install/setup.bash

ros2 launch turtlebot3_waypoint_patrol patrol.launch.py
```

실행 경로:

```text
A → B → C → D → A → 종료
```

## 주의사항

- 터미널 3에서는 조이스틱을 실행하지 않는다.
- 순찰 중 RViz에서 Goal이나 Pose Estimate를 보내지 않는다.
- 처음 시험할 때는 로봇 가까이에서 즉시 정지할 준비를 한다.
- 긴급 정지는 터미널 4에서 `Ctrl+C`를 먼저 누른다.
- 필요하면 터미널 1에서도 `Ctrl+C`를 눌러 본체 노드를 종료한다.
