# 터틀봇3 모든 제스처 설명서

최종 갱신: 2026-08-24  
제스처 화면: `http://192.168.2.46:5000`

## 현재 제어 방식

- D-Pad 방식은 사용하지 않습니다.
- SLAM·Nav2는 항상 실행합니다.
- 제스처 모드만 ON/OFF하여 Nav2 자율주행과 손 제스처 수동조작 사이의 속도 제어권을 바꿉니다.
- 제스처 모드 기본값은 OFF(AUTO/Nav2)입니다.
- 터틀봇 하드웨어는 mux의 단일 출력 `/cmd_vel_muxed`만 받으므로 Nav2와 제스처 속도가 동시에 적용되지 않습니다.

## 제스처 모드 ON/OFF

| 손 모양 | 기능 |
|---|---|
| 다른 네 손가락을 접고 엄지만 위로 👍 | 짧게: 제스처 모드 ON / 제스처 모드에서 1.5초 유지: OFF 후 AUTO/Nav2 |
| 엄지와 검지 끝을 붙이고 나머지 세 손가락을 편 OK 사인 👌 | 짧게: 컨트롤러 모드 ON / 손을 풀고 다시 1.5초 유지: OFF 후 AUTO/Nav2 |
| 다른 네 손가락을 접고 엄지만 아래로 👎 | 현재 모드 전환에 사용하지 않음 |

- ON/OFF를 바꿔도 SLAM과 Nav2 노드는 종료되지 않습니다.
- 제스처 모드 상태는 ROS 2 `/gesture_mode` Bool 토픽으로 확인할 수 있습니다.
- ON으로 전환할 때 안전을 위해 정지 명령을 한 번 낸 다음 제스처 명령을 적용합니다.
- OFF로 전환하면 진행 중인 제스처 상대 이동을 중지하고 AUTO/Nav2로 돌아갑니다.

## 조이스틱 모드

- OK 사인(👌)을 짧게 한 번 보여주면 조이스틱 ON입니다.
- ON에 사용한 손을 한 번 풀고, 다시 OK 사인을 1.5초간 유지하면 조이스틱과
  제스처가 모두 OFF되고 AUTO/Nav2로 돌아갑니다.
- 같은 OK 사인을 유지해도 한 번만 토글됩니다.
- 조이스틱 ON은 Nav2와 일반 손 제스처보다 우선합니다.
- ON 전환 시 진행 중인 손 제스처 이동을 취소하고 제스처 모드를 OFF로 만듭니다.
- OFF 전환 시 AUTO/Nav2로 복귀합니다.
- 왼쪽 스틱 상하: 전진·후진, 왼쪽 스틱 좌우: 좌·우 회전입니다.
- 데드존 0.12, 최대 직선 속도 0.08m/s, 최대 회전 속도 0.6rad/s입니다.

## 제스처 동작표

| 손 모양 | 인식 이름 | 터틀봇 동작 |
|---|---|---|
| 주먹 | `fist` | 즉시 정지 |
| 검지 1개 | `finger` | 전진 1m |
| 검지·중지 2개 | `two` | 후진 1m |
| 손가락 3개 | `three` | 우회전 90° |
| 검지·중지·약지·새끼 4개, 엄지는 접음 | `four` | 좌회전 90° |
| 엄지까지 다섯 손가락을 모두 편 손의 손등 | `back` | RViz에서 마지막으로 찍어 저장한 2D 목표 좌표로 Nav2 이동 |
| 엄지까지 다섯 손가락을 모두 편 손바닥으로 좌우 3회 흔들기 | `wave` | 제자리 180° 회전 |

## 4손가락과 흔들기 구분

- 좌회전 90°는 **엄지를 접고 나머지 네 손가락만** 폅니다.
- 180° 흔들기는 **엄지까지 다섯 손가락을 전부** 편 손바닥으로 합니다.
- 흔들기는 직전 좌우 극점을 기준으로 화면 너비 약 5% 이상 왕복한 횟수를 셉니다.
- 손을 화면 안으로 가져오는 최초 이동은 흔들기로 세지 않습니다. 반대 방향 이동까지 확인돼야 흔들기 판정이 시작됩니다.
- 빠르게 흔들다 손 검출이 한두 프레임 빠져도 3초 이내에는 누적 횟수를 유지합니다.

## 1m·90° 원샷 이동 규칙

- 한 번 포즈가 확정되면 손을 내려도 정해진 1m 또는 90°까지 계속 움직인 뒤 자동 정지합니다.
- 거리는 시간 계산이 아니라 TurtleBot3 `/odom`으로 측정합니다.
- 같은 포즈를 계속 들고 있으면 한 번만 실행합니다.
- 실행 중 다른 명확한 손가락 포즈가 들어오면 기존 동작을 즉시 중단합니다.
- 새 포즈가 확정된 순간의 위치와 방향을 기준으로 새 1m 또는 90° 동작을 바로 시작합니다.
- 예: 3손가락 우회전 중 엄지를 접은 4손가락을 보이면 우회전을 중단하고 즉시 좌회전 90°를 새로 시작합니다.
- 새 손은 같은 위치에서 3프레임 연속 검출돼야 획득합니다. 이동 포즈는 3프레임,
  손등과 OK 사인은 4프레임을 확인한 뒤 확정합니다. 주먹 정지는 손이 획득된 뒤 즉시 반영합니다.
- `/odom`이 없거나 0.5초 이상 오래되면 원샷 동작을 시작하지 않거나 즉시 취소합니다.

## 주먹 비상정지

- 대기 중 주먹은 즉시 속도 0을 출력합니다.
- 원샷 이동 중에는 손가락을 바꾸는 순간 생기는 짧은 주먹 오인을 막기 위해 약 0.25초 이상 유지했을 때 동작을 취소합니다.
- 취소한 동작은 주먹을 풀어도 자동 재개되지 않습니다.

## RViz 저장 좌표 이동

1. RViz에서 `2D Goal Pose`로 원하는 2D 목표 좌표와 방향을 찍습니다.
2. 브리지가 마지막 `/goal_pose`를 저장합니다.
3. 제스처 모드를 ON으로 하고, 다섯 손가락을 모두 편 손의 손등을 카메라에 보여줍니다.
4. 제스처 상대 이동을 중지하고 저장 좌표를 Nav2 `NavigateToPose`에 전달합니다.
5. 목표가 접수되면 제스처 모드를 OFF로 바꿔 Nav2가 이동을 담당합니다.

- 저장된 목표가 없거나 Nav2 서버가 준비되지 않았으면 이동하지 않습니다.
- Nav2 목표 이동 중 주먹을 보이면 목표를 취소하고 정지합니다.

## 카메라와 인식 기준

- 현재 사용 카메라는 `/dev/video0`, `/dev/video2` 두 대이며 각각 640×480, 15FPS입니다.
- 손 주변 ROI 크롭 없이 전체 프레임의 같은 좌표계에서 연속 추적합니다.
- 손가락 개수는 실물 카메라 구도에서 안정적인 화면 랜드마크를 우선 사용합니다.
- 손가락이 카메라 쪽을 향해 화면에서 짧아지는 경우에는 3D 랜드마크의 펴짐 정보를 함께 사용합니다.
- 손가락 개수·OK 사인·손등은 손의 화면 내 회전과 무관하게 판정합니다.
- 엄지 ON/OFF는 화면의 위·아래가 아니라 손목에서 중지 뿌리로 향하는 손바닥 축을 기준으로 판정하므로 손을 기울여도 동작합니다.
- 흔들기는 손의 기울기와 무관하지만 동작 자체는 화면 기준 좌우 왕복으로 합니다.
- 손 검출·존재 신뢰도는 0.65, 추적 신뢰도는 0.60 이상이어야 합니다.
- 손 폭이 프레임 폭의 5%보다 작으면 후보에서 제외하고, 같은 위치에서 3프레임
  연속 검출되지 않은 후보도 버립니다. 입·책상 무늬 같은 오탐을 줄이기 위한 기준입니다.
- 카메라나 터틀봇이 움직일 때 손 커서가 같이 밀리는 현상은 배경 광학 흐름의 이동·회전·배율을 보정합니다.
- 손 전체가 화면에 들어오고 손 크기가 화면 높이의 약 20~50%가 되게 하면 가장 안정적입니다.
- 강한 역광을 피하고 손가락 사이를 분명히 벌립니다.

## 속도 제어 경로

- Nav2: `/cmd_vel` → mux
- 제스처 브리지: `/cmd_vel_gesture` → mux
- 조이스틱: `/cmd_vel_joy` → mux
- mux 최종 출력: `/cmd_vel_muxed` → `turtlebot3_node`
- 제스처 모드 OFF일 때 mux는 Nav2 입력만 선택합니다.
- 제스처 모드 ON일 때 mux는 제스처 입력만 선택합니다.
- 조이스틱 모드 ON일 때 mux는 다른 입력보다 조이스틱을 우선 선택합니다.
- 선택된 입력이 0.5초 이상 끊기면 mux가 정지 속도를 출력합니다.

## 안전 확인

- 로봇 주변의 사람과 장애물을 치운 뒤 시험합니다.
- 처음에는 바퀴가 자유롭게 뜬 상태 또는 넓은 공간에서 포즈별로 확인합니다.
- 긴급 정지는 주먹을 약 0.25초 유지합니다.
- 제스처 서버 연결 중단, 오래된 명령, `/odom` 중단 시 로봇은 정지합니다.
