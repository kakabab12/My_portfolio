# TurtleBot3 통합 제어 작업 정리 — 2026-08-21

## 목적

터틀봇3를 저장 지도 기반 Nav2/AMCL 자율주행, 카메라 제스처, Xbox 조이스틱,
웹 상태 화면으로 한 번에 실행합니다. 오늘의 경로는 다음과 같습니다.

```text
A ── Nav2 자율주행 ──> B ── 제스처 ──> C ── 컨트롤러 ──> D ── Nav2 자율주행 ──> A
```

> 이 구성은 새 지도를 만드는 SLAM 모드가 아니라,
> `factory_map_20260821.yaml` 저장 지도를 쓰는 **Nav2 + AMCL 위치 추정** 모드입니다.

## 한 번에 실행하기

### 바탕화면 아이콘

바탕화면의 `TurtleBot3 전체 실행` 아이콘을 더블클릭합니다.

- 파일: `/home/user/Desktop/TurtleBot3_전체실행.desktop`
- GNOME 신뢰 실행 속성과 실행 권한을 설정했습니다.

### 터미널 실행

```bash
cd /home/user/sw/robot
./scripts/turtlebot3_전체실행.sh
```

이 실행 파일은 아래 항목을 모두 시작합니다.

1. OpenCR 기반 TurtleBot3 bringup (`/dev/ttyACM0`)
2. 제스처 서버와 카메라 2대
3. 속도 mux
4. Xbox 조이스틱 (`/dev/input/js0`)
5. 오늘의 저장 지도 기반 Nav2/AMCL
6. A-B-C-D-A 구간별 제어권 미션

실행 직후 로봇은 A에서 B로 자율주행을 시작합니다. **시작 전 로봇을 실제 A 위치와
방향에 맞춰 두고, 이동 경로를 비워야 합니다.** 종료는 실행한 터미널에서 `Ctrl+C`입니다.

## A-B-C-D-A 동작 규칙

| 구간 | 제어 방식 | 도착 판정 | 다음 동작 |
| --- | --- | --- | --- |
| A → B | Nav2 자율주행 | Nav2 action 성공 | 자동으로 제스처 모드 전환 |
| B → C | 제스처 | AMCL 좌표가 C 반경 18cm 안에 1초 유지 | C 도착 완료 표시, 컨트롤러 전환 대기 |
| C → D | 조이스틱 | AMCL 좌표가 D 반경 18cm 안에 1초 유지 | D 도착 완료 표시, 자율주행 복귀 대기 |
| D → A | Nav2 자율주행 | Nav2 action 성공 | A 복귀 완료, 미션 종료 |

### 제스처와 컨트롤러 전환

- A→B 자동 구간에서는 손이 카메라에 보여도 제어권이 바뀌지 않습니다.
- B에 Nav2가 도착하면 자동으로 **제스처 모드**가 됩니다. 제스처로 C까지 이동합니다.
- C 도착 완료가 화면에 뜬 뒤 **OK 사인**을 하면 **컨트롤러 모드**가 됩니다. 조이스틱으로 D까지 이동합니다.
- D 도착 완료가 화면에 뜬 뒤 **OK 사인(👌)을 1.5초 유지**하면 조이스틱·제스처 모드가 모두 꺼지고 Nav2가 D에서 A로 복귀합니다.
- 제스처 모드에서 따봉(👍)을 1.5초 유지하면 수동 제어를 끄는 동작도 유지됩니다. 단, D 도착 전에는 A 복귀 목표가 시작되지 않으므로 로봇은 정지 상태가 됩니다.

수동 구간에서도 `/amcl_pose`는 계속 갱신됩니다. 따라서 C와 D는 단순히 사용자가
“도착했다”고 누르는 방식이 아니라 지도 좌표로 판정합니다. 판정은 위치(x, y)만
사용하며 도착 방향(yaw)은 현재 조건에 포함하지 않습니다.

## 웹 화면

제스처 서버의 상태 페이지에서 다음을 볼 수 있습니다.

- 카메라 2대: `/dev/video0`, `/dev/video2`
- 현재 제어 모드: 자율주행 / 제스처 / 컨트롤러
- 현재 미션 단계와 목표 지점
- A, B, C, D 각각의 완료 상태
- 실시간 AMCL 지도 좌표(x, y)

주요 API:

```text
GET  /                         상태 화면
GET  /health                   카메라 상태
GET  /control_mode             현재 제어 모드
GET  /mission_status           미션·체크포인트·현재 좌표
POST /mission_status           미션 노드의 상태 보고용
```

## 확인된 하드웨어

- OpenCR: `/dev/ttyACM0`
- 조이스틱: `/dev/input/js0` (Xbox 360)
- 제스처 카메라: `/dev/video0`, `/dev/video2` (Logitech C270 2대)

## 검증 상태와 주의 사항

- Python 문법 검사와 실행 스크립트 문법 검사는 통과했습니다.
- 웹 미션 상태 API와 실제 ROS2 노드가 함께 동작하는 최종 실주행은, 로봇을 A에
  배치한 안전한 공간에서 한 번 확인해야 합니다.
- A→B와 D→A 구간 중 Nav2가 실패하면 미션은 정지하며, 속도 mux는 0 속도만
  전달하도록 잠깁니다. 웹 화면에서 오류 상태를 확인한 뒤 원인을 점검합니다.
- 다른 Nav2/bringup 프로세스가 이미 실행 중이면 통합 실행 파일은 중복 실행을
  막습니다. 기존 실행을 먼저 정상 종료한 뒤 다시 시작합니다.
