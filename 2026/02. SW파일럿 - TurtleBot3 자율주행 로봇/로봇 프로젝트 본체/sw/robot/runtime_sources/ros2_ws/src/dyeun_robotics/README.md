# SW Pilot 로보틱스 PBL

## 프로젝트 개요

SW Pilot 로보틱스 과정의 PBL(Problem-Based Learning) 학습 기록입니다.

## PBL 주제
**공정 간 자율 운반 로봇 프로토타입 개발**

바닥에 그려진 검은 선을 따라 스스로 움직이면서 이동 기록을 남기는 라인트레이싱
운반 로봇을 만듭니다.
