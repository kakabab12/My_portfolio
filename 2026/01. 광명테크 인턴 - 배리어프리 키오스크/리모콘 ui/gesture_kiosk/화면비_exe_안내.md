# 화면비별 실행 파일 6개

기준점 3가지 × 화면비 2가지입니다. 쓸 것을 두 번 눌러 실행하면 됩니다.

| 기준점 | 16:9 가로 모니터 | 9:16 세로 키오스크 |
|---|---|---|
| 코끝 | `head_16-9_데스크탑.exe` | `head_9-16_키오스크.exe` |
| 눈썹 | `eyebrow_16-9_데스크탑.exe` | `eyebrow_9-16_키오스크.exe` |
| 이마 | `forehead_16-9_데스크탑.exe` | `forehead_9-16_키오스크.exe` |

전부터 있던 `head.exe` / `eyebrow.exe` / `forehead.exe`도 그대로 둡니다. 그쪽은
화면비를 **자동**으로 잡습니다 — 세로가 더 긴 화면이면 키오스크, 아니면
데스크탑입니다. 한 대에서 화면비가 안 바뀐다면 그것만 써도 됩니다. 위 6개는
자동 판정에 맡기지 않고 못을 박아 두고 싶을 때(설치 현장, 배포본) 쓰십시오.

exe는 얇은 실행기입니다. 안에서 하는 일은 이것과 같습니다.

```
py -3.11 forehead.py --aspect desktop
```

그래서 **exe는 반드시 `forehead.py`와 같은 폴더에 두어야 합니다.** exe만 따로
옮기면 엔진을 못 찾습니다(그때는 무엇이 없는지 콘솔에 찍힙니다). 붙여 주는
`--aspect`는 기본값일 뿐이라, 뒤에 직접 `--aspect`를 주면 그쪽이 이깁니다.

## 다시 빌드하려면

```
make_aspect_exes.bat
```

여섯 개를 임시 venv 하나에서 한 번에 만듭니다. PyInstaller는 그 임시 venv에만
설치했다가 끝나면 지웁니다 — 시스템 파이썬은 안 건드립니다. 진입 스크립트
(`scripts/exe_entries/`)도 빌드할 때마다 다시 찍어 내므로 손으로 고치지 마세요.
로직은 `scripts/aspect_launcher_common.py` 한 벌뿐입니다.

## 화면비가 실제로 바꾸는 것 — 카메라 크롭 하나

엔진 파일은 여전히 셋(`head.py`, `eyebrow.py`, `forehead.py`)입니다. 화면비에
따라 달라지는 것이 **카메라 프레임 크롭 하나뿐**이라 여섯 벌로 나눌 이유가
없었습니다.

- 커서를 그리는 캔버스는 `GetSystemMetrics`로 잰 실제 화면 해상도를 그대로 씁니다.
- 얼굴이 향한 곳과 커서를 맞추는 겨냥 반폭은 EDID로 읽은 화면 실치수(mm)로
  계산합니다.

둘 다 이미 모니터를 직접 보고 정하므로 화면비 때문에 손댈 것이 없습니다. 남는
것은 크롭 하나이고, 그것 하나 때문에 1900줄짜리 엔진을 여섯 벌로 늘리면 오늘
같은 수정을 매번 여섯 군데에 반복해야 합니다(오늘 클릭 버그 수정만 해도 세
군데였습니다).

### 크롭이 뭘 하나

세로 크롭은 가로 프레임(1280×720)의 중앙만 남겨 9:16(405×720)을 만듭니다.
카메라를 물리적으로 돌리지 않고 세로 화면비를 맞추려고 넣은 것입니다.

가로 모니터에서 이걸 켜 두면 좌우 화각을 버리는 셈이라, 몸이 옆으로 움직이면
얼굴이 프레임 밖으로 나갑니다. 그래서 데스크탑 쪽은 크롭을 끕니다.

크롭을 꺼도 **인식 정확도는 안 떨어집니다.** 높이를 안 건드리므로 얼굴이
차지하는 픽셀 크기가 그대로이고, 추적은 두 눈 사이 거리로 정규화해서 재기
때문입니다. 대신 추론 프레임이 405×720에서 1280×720으로 커져 그만큼
무거워집니다 — 키오스크 쪽에서 크롭을 유지하는 이유이기도 합니다.
