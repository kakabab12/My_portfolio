## 기법별 전/후 비교를 볼 때 주의할 것

`04_기법별_전후비교.md`가 이 폴더에서 가장 중요한 문서입니다. 다만 **원값만
보면 틀린 결론이 나옵니다.**

감도를 올리면 신호도 인공물도 잡음도 **같은 비율로** 커집니다. 그래서 감도를
낮추는 기법은 모든 지표가 좋아진 것처럼 보이고, 올리는 기법은 나빠진 것처럼
보입니다. 반드시 **커서 이동폭으로 나눈 정규화 값**을 함께 보세요.

정규화하면 7개 기법 중 **진짜 개선은 셋**입니다(상대 회전 매핑, 얼굴 기준 좌표계,
렌즈 자가 보정). 나머지는 도달 범위나 대응 관계 같은 다른 것을 해결합니다.

## 다시 뽑는 법

```bash
py "데이터 수치/generate.py"          # 기본 수치
py "데이터 수치/ablation.py"          # 기법별 전/후 비교
py "데이터 수치/lens_ablation.py"     # 렌즈 자가 보정 (공정 비교, 15분)
py "데이터 수치/distance_scaling.py"  # 거리 조절 — 제자리와 이동 (30초)
py "데이터 수치/arc_t_gate.py"        # 곡률 판정을 t값으로 바꾸면 (시드 30개, 3분)
py "데이터 수치/mouth_cliff.py"       # 그림 3 — 입 다묾 절벽 (실제 판정 코드)
py "데이터 수치/arc_protocol_trap.py" # auto_arc 적합 기록 — 렌즈 비교 도중 무엇이 깨웠나 (30초)
py "데이터 수치/click_freeze_lookback.py"  # 클릭 붙잡기의 되짚기와 드래그 (가상 사용자)
py "데이터 수치/input_timing.py"      # 입 동작 시간만 바꾼 클릭 판정 (가상 사용자)
py "데이터 수치/arc_realistic_state.py"  # 실사용 2분 뒤 auto_arc 상태와 휨 (6분)
py -3.11 "데이터 수치/lens_speed.py"   # 렌즈 보정 한 번의 시간 — 설치 조합마다 (CSV에 덧붙임)
py -3.11 "데이터 수치/lens_divergence.py"  # 얼굴마다 보정 시도 수와 CPU 시간 — 발산하는 얼굴 (3분)
```

프로젝트 루트(`gesture_kiosk/`)에서 실행하면 CSV가 이 폴더에 다시 떨어집니다.
난수 씨앗을 고정해 두어 몇 번을 돌려도 같은 값이 나옵니다. 예외는 **걸린 시간**
열입니다 — PC와 부하에 따라 달라집니다. `lens_speed.py`는 조합끼리 견주려고 CSV를
덮어쓰지 않고 한 줄씩 덧붙이고, `lens_divergence.py`는 시도 수·결과는 같게 나오고
시간 열만 달라집니다(보정 스레드는 우선순위가 가장 낮아 PC가 바쁘면 벽시계만 늘어난다 —
그래서 스레드 CPU 시간을 따로 적는다).

## 삭제한 기법 (2026-09-24)

곡률 자동 보정(`auto_arc`)을 코드에서 지웠다(`05_렌즈보정_전후비교.md` 6절 근거).
그래서 **auto_arc를 켜고 잰 측정은 지금 판에서 다시 돌릴 수 없다** —
`lens_ablation.py`(⑩ 줄), `arc_t_gate.py`, `arc_protocol_trap.py`,
`arc_realistic_state.py`. 지금 돌리면 설정이 조용히 무시돼 다른 값이 나오는 대신
안내를 내고 멈춘다(`ablation.build()`의 멈춤 장치). 다시 돌리려면 저장소 이력에서
삭제 직전 판을 꺼낸다. 이미 남긴 CSV는 그 판에서 잰 값이다.

렌즈 배럴 왜곡 되돌리기(k1), 머리 자세 각도 매핑, 입 오므리기 재정렬도 같은 날
지웠다. 이 폴더의 측정 스크립트는 이 셋을 켜지 않으므로 영향이 없다.

## 못 뽑은 것

- **입 벌림에 의한 커서 밀림** — 가상 카메라가 입을 벌릴 때 코가 딸려 움직이는
  변형을 모형에 넣지 않았습니다. 시뮬레이션으로 측정하면 0이 나오는데 그건 사실이
  아닙니다. **테스트 측정이 필요합니다.**
- **저조도 인식률** — 조명 모형이 없습니다. 테스트 측정치는 `01_테스트_측정치.md` 참고.
- **사용자 수행 지표**(과제 완료 시간, ISO 9241-411 처리량) — 참가자를 모집한
  실험이 없습니다. 논문의 가장 큰 공백입니다.
