# forehead.py 설정 가이드

이 문서는 `forehead.py`(코-눈 혼합점 기준 헤드트래커)를 처음 보는 사람이
설정값을 이해하고 직접 조정할 수 있도록 만든 안내서입니다. 코드를 열지
않아도 이 문서만으로 대부분의 튜닝이 가능하게 정리했습니다.

---

## 1. 이 프로그램은 무엇인가

손을 쓰기 어려운 사용자를 위해 **고개 움직임과 입 벌리기만으로 마우스를
대체**하는 프로그램입니다. 카메라로 얼굴을 보고, 실제 윈도우 마우스
포인터를 옮기고 클릭까지 합니다.

- `py forehead.py` 로 실행 (또는 `forehead.exe` 더블클릭)
- 종료: 콘솔에 `quit` + Enter, 또는 창이 보이면 `q`/`ESC`
- 실제 마우스 제어 켜기/끄기: 콘솔에 `p` + Enter
- 카메라 미리보기 켜기/끄기: 콘솔에 `cam on` / `cam off` + Enter

**커서를 움직이는 원리**: 고개를 돌리면 두 눈 사이 중점을 기준으로 "미간
근처의 한 점"(코끝 쪽으로 살짝 당긴 점)이 얼마나 벗어났는지를 측정해서 커서
위치로 바꿉니다. 몸 전체가 움직이는 건 상쇄되고, 고개 움직임만 반영됩니다.

---

## 2. 설정값은 전부 이 파일 안에 있다

`forehead.py` 안에 상수로 다 모여 있습니다(별도 설정 파일 없음). 아래
표의 이름으로 파일 안에서 검색(Ctrl+F)하면 바로 그 줄이 나옵니다.

### 커서 반응성

| 이름 | 뜻 | 조정 방법 |
|---|---|---|
| `SENSITIVITY_X_OVERRIDE` | 좌우 감도 | 회전이 둔하면 올리고, 너무 예민하면 낮춥니다 |
| `SENSITIVITY_Y_OVERRIDE` | 상하 감도 | 위와 동일 (세로는 원래 좌우보다 낮게 잡는 게 정상 — 고개가 상하보다 좌우로 더 많이 돕니다) |
| `FOREHEAD_NOSE_BLEND_RATIO` | 커서 기준점을 코끝 쪽으로 얼마나 당길지(0~1) | 0에 가까우면 미간에 가깝고 회전 신호가 작음(둔함), 1에 가까우면 코끝과 같아지고 회전은 좋지만 좌우로 움직일 때 살짝 휘어지는 현상·입 벌릴 때 커서 밀림이 커짐. **지금 0.3** — 이 셋의 절충점 |
| `TOP_HALF_Y_SCALE` | 커서가 화면 세로 몇 %까지 내려가는지(0~1) | 화면 하단 요소(안내 배너 등)에 커서가 안 닿으면 올립니다. 1.0이면 화면 전체 |

### 클릭 · 드래그

| 이름 | 뜻 |
|---|---|
| `MOUTH_OPEN_MARGIN_OVERRIDE` | 입을 얼마나 벌려야 "벌렸다"로 인정하는지 |
| `MOUTH_HOLD_SEC` | 이 시간 이상 계속 벌리면 클릭 대신 꾹 누르기(드래그)로 전환 |
| `DOUBLE_CLICK_WINDOW_SEC` | 이 시간 안에 두 번째 입 벌림이 오면 더블클릭으로 처리 |

### 저조도(어두운 곳) 대응

| 이름 | 뜻 |
|---|---|
| `LOW_LIGHT_ENHANCEMENT_ENABLED` | 저조도 보정 켜짐/꺼짐 |
| `LOW_LIGHT_MEAN_LUMA_THRESHOLD` | 이 평균 밝기(0~255) 미만일 때만 보정 적용 |
| `LOW_LIGHT_CLAHE_CLIP_LIMIT` | 클수록 어두운 곳 대비를 더 세게 올림(잡음도 더 증폭) |

인식용 프레임에만 적용되고, 화면에 보이는 미리보기 색감은 그대로입니다.

## 3. cam on 화면 색깔 범례

콘솔에 `cam on` + Enter를 치면 카메라 미리보기가 뜹니다. 색깔이 무엇을
가리키는지:

| 색 | 의미 |
|---|---|
| 초록 원 (십자 포함) | 실제 커서 위치 |
| 노란 점 "혼합점" | 커서를 계산하는 기준점(코-눈 혼합점) |
| 하늘색 점 2개 "눈" | 두 눈 바깥쪽 끝(원재료) |
| 마젠타 십자 "원점(눈 중점)" | 좌표계의 원점 |
| 빨간 점 "코끝" | 코끝 원재료(혼합 전) |
| 회색 선 | 원점→코끝 축 — 노란 점이 이 선 위 어디쯤 있는지 |

기준점이 엉뚱한 곳에 찍히면(예: 이마 위, 입 근처) 카메라 각도나 얼굴
인식 문제일 수 있습니다.

## 4. 자주 겪는 문제와 조정

| 증상 | 조정할 상수 |
|---|---|
| 몸을 움직이면 커서도 움직입니다 | `FACE_LOCAL_MAPPING`이 `True`인지 확인(기본 켜짐 — 이게 꺼지면 이 문제가 재발합니다) |
| 고개를 돌려도 커서 반응이 둔합니다 | `SENSITIVITY_X_OVERRIDE`↑ 또는 `FOREHEAD_NOSE_BLEND_RATIO`↑ |
| 좌우로 움직일 때 커서가 곡선을 그립니다 | `FOREHEAD_NOSE_BLEND_RATIO`↓ (코 성분을 줄입니다) |
| 입 벌려 클릭하려 하면 커서가 밀립니다 | `FOREHEAD_NOSE_BLEND_RATIO`↓ |
| 화면 하단(안내 배너 등)에 커서가 안 닿습니다 | `TOP_HALF_Y_SCALE`↑ |
| 어두운 곳에서 인식이 잘 안 된다 | `LOW_LIGHT_MEAN_LUMA_THRESHOLD`↑ (더 밝은 조건까지 보정 켜짐), `NOSE_CLUSTER_AVERAGING`이 `True`인지 확인 |
| 가만히 있어도 커서가 떨립니다 | `ONE_EURO_MIN_CUTOFF`↓ |
| 빠르게 고개를 돌릴 때 반응이 늦다 | `ONE_EURO_BETA`↑ |

값을 바꾼 뒤에는 반드시 다시 실행해서 확인하고, exe로 배포하는 경우
`make_forehead_exe.bat`을 다시 실행해 재빌드해야 반영됩니다.

## 6. 상업적 사용 가능 여부 (라이선스 검토)

이 프로그램(및 exe 빌드)에 실제로 들어가는 것들만 정리했습니다.

| 구성 요소 | 라이선스 | 상업적 사용 | 비고 |
|---|---|---|---|
| MediaPipe (얼굴 랜드마크 모델 포함) | Apache License 2.0 | **가능** | 코드 공개·저작자 표시 의무 없음. 배포물에 라이선스 고지문 동봉 권장 |
| OpenCV (opencv-contrib-python) | Apache License 2.0 (4.5+) | **가능** | 특허 있던 옛 알고리즘(SIFT 등)도 특허 만료로 자유화됨. 이 프로젝트가 쓰는 기능(카메라 캡처·CLAHE 등)은 전부 문제 없음 |
| NumPy | BSD-3-Clause | **가능** | 허가형 라이선스, 제약 없음 |
| PyYAML | MIT | **가능** | 허가형 라이선스, 제약 없음 |
| psutil | BSD-3-Clause | **가능** | 허가형 라이선스, 제약 없음 |
| Pillow (PIL) | MIT-CMU | **가능** | 코드에서 한글 텍스트 렌더링에 직접 씀(`put_korean_text`). ⚠ **requirements.txt에 빠져 있음** — MediaPipe가 의존하는 matplotlib을 통해 딸려 들어와 있을 뿐 직접 명시되어 있지 않습니다. 다른 PC에 새로 설치할 때 버전이 안 맞을 위험이 있으니 requirements.txt에 추가를 권장 |
| PyInstaller (exe 빌드 도구) | GPL v2 + 예외 조항 | **가능** | PyInstaller 라이선스에 명시된 예외로, **이 도구로 빌드한 실행 파일 자체는 GPL의 영향을 받지 않는다** — 상용·비공개 프로그램을 빌드해 배포해도 무방. 빌드 도구 자체이지 배포물에 포함되는 게 아니다 |
| 1€ 필터 (OneEuroFilter) | 해당 없음(알고리즘) | **가능** | 논문(Casiez et al., CHI 2012)에 공개된 수식을 직접 구현한 것 — 특정 소스코드를 가져온 게 아니라 라이선스 이슈 자체가 없다 |
| CLAHE | 해당 없음(알고리즘, OpenCV 내장 함수 사용) | **가능** | 위 OpenCV 라이선스에 포함. 기법 자체(Zuiderveld, 1994)도 특허 아님 |

**결론 — 지금 구성 전부 상업적 사용에 문제없습니다.**

**권장 조치 하나**: `requirements.txt`에 `Pillow`가 빠져 있습니다. 지금은
MediaPipe의 다른 의존성(matplotlib)을 통해 우연히 설치되어 있지만, 이건
"명시적으로 요구한 것"이 아니라서 향후 MediaPipe 버전이 바뀌어 matplotlib
의존이 빠지면 `forehead.py`가 못 뜨는 사고로 이어질 수 있습니다.
`requirements.txt`에 `pillow` 줄을 직접 추가하는 걸 권합니다.
