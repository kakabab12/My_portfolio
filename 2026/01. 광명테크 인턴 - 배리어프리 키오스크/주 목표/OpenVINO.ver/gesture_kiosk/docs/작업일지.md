## 2026-07-27

### 1. 인식 정확도 — 손가락/주먹 오분류 재발
- 증상: 손가락 하나를 펴고 움직여도 주먹용 이벤트(`back`/`home`/`ok`)가 튀어나옴.
- 원인(실기 진단 로그로 확인): 검지를 펴도 관절 비율(ratio)이 1.17~1.47 사이에
  머무는데, `extend_ratio`가 1.5로 설정돼 있어 "폄" 판정을 못 받고 계속
  "기권"으로 빠짐 — 기권이 하나라도 있으면 주먹도 손가락도 확정하지 않으므로
  결국 판정이 흔들리다 주먹 쪽으로 넘어감.
- 수정: `extend_ratio` 1.5→1.3. 단순히 낮추기만 하면 비율만 우연히 높은 굽힌
  손가락까지 폄으로 잘못 셀 위험이 있어, "폄" 판정에 방향(코사인, 안 굽힘)
  조건을 추가로 요구하도록 방어선을 넣었습니다.
- 좌우/상하 방향(swipe) 판정 로직 자체는 문제없음을 확인만 하고 손대지 않음.
- 파일: `src/postprocess/hand_shape.py`
- 검증: 실기 라이브 테스트로 확인 — 10회 반복 기준 전체 제스처 85% 이상 인식
  (기획서 KPI 목표치 충족).

### 2. 사용자 잠금 — 가장 가까운 사람 우선
- 요청: "처음 화면에 잡힌 사람"이 아니라 "가장 가까운 사람"을 잠그게 해달라.
- 적용 범위: **최초 잠금 시에만** 적용 — 이미 잠긴 뒤의 "다른 사람에게 안
  뺏기는" 로직(2026-07-22, 대기줄 잠금 전이 버그 수정)은 그대로 유지해
  과거에 고쳤던 문제가 재발하지 않게 했습니다.
- 적용: `person_lock.sharpness_weight` 0.5 → 0.0 (선정 점수를 얼굴 선명도 대신
  크기=근접도만 보게 함).
- 파일: `configs/config.yaml`

### 3. 카메라 전환 (위/아래 2대)
- 키오스크에 카메라가 위/아래 2대 있어, 디버그 창에서 키 입력으로 전환할 수
  있게 해달라는 요청.
- 적용: 디버그 창(`run.bat` 카메라 창)에서 **`c` 키**로 두 카메라를 번갈아 전환.
  - 전환 시 사용자 잠금·궤적 추적 상태를 새로 초기화(시점이 바뀌므로).
  - 보조 카메라가 없거나 연결이 빠져 있어도, 기존 카메라를 내리기 전에
    새 카메라를 먼저 열어보고 성공해야 교체하도록 순서를 짜서 — 전환
    실패해도 파이프라인이 죽지 않고 기존 카메라로 계속 동작.
- 파일: `src/capture/camera_stream.py`, `src/pipeline/realtime_loop.py`,
  `scripts/run_demo.py`, `configs/config.yaml`(`camera.device_id_alt`)

### 4. CPU + Intel 내장그래픽 동시 추론 (신규, 미검증)
- 추론 처리량을 늘리기 위해 CPU와 Intel iGPU를 동시에 쓰는 2단 파이프라인을
  준비. 기본은 꺼둔 상태(`model.dual_device.enabled: false`).
- 개발 PC는 별도 dGPU(MX250)가 OpenVINO GPU 슬롯을 차지해 이 개발 환경에서는
  실측 검증이 불가능했다 — 실제 키오스크(dGPU 없음, iGPU만 있음)에서
  켜고 실측해야 한다(`docs/TODO.md` №13 참고).
- iGPU를 쓰려면 Intel Graphics Compute Runtime(컴퓨트 드라이버)이 별도로
  필요 — 없으면 자동으로 CPU 단독으로 안전하게 되돌아갑니다.
- 파일: `src/inference/pose_estimator.py`

### 5. 오프라인 설치 안정화
- 기존 wheelhouse(오프라인 설치 번들)에 `openvino` 패키지가 없는 상태에서
  `install.bat`을 돌리면, 필수 패키지 전체 설치가 통째로 실패하는 문제를 확인.
- 수정: `openvino`를 필수 목록(requirements.txt)에서 빼고 별도 설치 단계로
  분리 — 실패해도 나머지 필수 패키지 설치는 막히지 않고, `openvino`가 없으면
  자동으로 onnxruntime 백엔드로 안전하게 돌아갑니다.
- 파일: `install.bat`, `make_offline_bundle.bat`, `requirements.txt`

### 6. 기타
- `run.bat`을 기본 실행만으로도 디버그 창(카메라 화면)이 뜨게 변경
  (`--debug` 안 붙여도 됨).
- 추론 검출 간격(`det_interval_frames`)을 늘려 FPS를 더 뽑을 수 있는지
  검토 — 실측 결과 이득은 미미한데 반해, 사람 추적 캐시를 오래 재사용하게 돼
  팔을 크게 휘두르는 도중 놓칠 위험이 커져 **현재 값 유지로 결론**.
- 단위 테스트 121건 → 130건으로 증가(카메라 전환·이중 디바이스 로직 테스트
  추가), 전부 통과.
