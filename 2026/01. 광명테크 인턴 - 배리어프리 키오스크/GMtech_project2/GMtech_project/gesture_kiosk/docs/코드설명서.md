# 코드 설명서 — gesture_kiosk 추론 엔진 (2026-08-03)

> **누구를 위한 문서인가**: 이 코드를 처음 보는 사람이 "어느 파일이 무슨 일을
> 하는지, 고치고 싶은 게 있으면 어디를 열어야 하는지"를 10분 안에 잡게 하는 지도.
> 상세한 "왜"는 각 파일 첫머리 독스트링과 config 주석에 날짜와 함께 남아 있다 —
> 이 문서는 길잡이만 합니다.

---

## 1. 한 장 요약 — 데이터가 흐르는 길

```
카메라(USB 웹캠)
  │  CameraStream — 별도 스레드가 프레임을 계속 읽는다 (끊기면 자동 재연결)
  ▼
전처리 Preprocessor — 거울 반전 (사용자 기준 좌/우 일치)
  │
  ├─▶ [머리 앵커 스레드] HeadDetector(포즈) — 초당 10회, 사용자 머리 위치 관측
  │        └─ 마스크·모자 무관 (몸 실루엣으로 잡음). 손 루프와 병렬 — FPS 영향 없음
  ▼
손 인식 HandTracker(MediaPipe) — 프레임 속 손들의 21점 랜드마크
  │        └─ 원거리면 앵커 주변만 잘라 추론(ROI 줌 — 먼 손도 크게 보이게)
  ▼
사용자 손 선별 HandSelector — "누구의 어떤 손을 볼 것인가"
  │   ① 앵커 게이트: 가장 가까운 사람의 머리 반경 + **그 사람 손목 반경** 안 손만
  │      통과 (옆 사람 차단 — 손목 기준이라 판정 영역이 내 팔을 따라다닌다)
  │   ② 단일 손 추적: 움직여서 지시한 손 **하나**를 연속성으로 고정
  ▼
동작 판정 GestureFilter — "그 손이 무슨 동작을 했는가"
  │   손 모양(주먹/한 손가락/손바닥) × 쓸기 방향 + 제자리 더블 탭
  ▼
이벤트 전송 event_sender — stdout에 한 줄 출력 → 델파이 UI가 파이프로 수신
```

실행 진입은 **main.py** 하나입니다. 델파이(또는 사람이) `python.exe main.py`로 띄우면
위 파이프라인이 스레드로 돌고, 이벤트가 stdout에 한 줄씩 나옵니다.

## 3. 핵심 개념 사전 — 코드를 읽을 때 만나는 단어들

| 개념 | 한 줄 설명 | 코드 위치 |
|---|---|---|
| **앵커 자(尺)** | 도달·손목 반경의 단위는 **어깨너비** — 귀-귀 폭은 고개만 돌려도 71% 무너져 반경이 함께 쪼그라들었다(2026-08-04 실측). 중심은 머리 그대로(어깨로 내리니 위쪽 도달이 줄어 손이 잘렸습니다) | hand_select `anchor_frame` |
| **앵커(anchor)** | "지금 사용자는 이 사람" — 가장 가까운 머리를 고정하고, 그 사람 **머리 반경 + 포즈 손목 반경** 둘 다 통과한 손만 후보 (2026-08-03: 머리 반경만으론 옆 사람 손과 내 뻗은 손이 같은 거리라 못 갈렸습니다) | hand_select `_update_head_anchor`, `_filter_hands_by_anchor` |
| **단일 손 추적** | 좌/우 라벨 없이 손 **하나**를 위치 연속성으로 추적. 획득=움직여 지시한 손, 해제=2초 소실 | hand_select `_update_tracked_hand`, `_acquire_tracked_hand` |
| **남 손 궤적 기억** | 내 손이 보이던 동안 **함께 보이던 손**은 내 손이 아니다 — 블러로 내 손이 끊긴 사이 쉬는 손이 정체성을 승계하는 것을 막는다 (2026-08-03) | hand_select `_update_other_tracks`, `_is_known_other_hand` |
| **앵커 고정** | 한번 잡은 사용자는 **쓰는 동안 안 바뀐다** — 여럿이 있어도 관측에서 잠깐 빠졌다고 다른 사람에게 넘어가지 않습니다. 해제는 세션 종료 후 | hand_select `_drop_expired_head_anchor` |
| **손 소유자 판정** | 두 사람 골격을 다 보고, 각 손에 대해 **누구 손목이 더 가까운가**로 주인을 정한다 — 임계값 없는 상대 비교. 난입자 손 차단의 핵심 | hand_select `_is_other_persons_hand` |
| **높이 우선** | 같은 프레임에 두 손이 획득 요건을 넘기면 **위에 있는 손**이 이긴다 — 배 앞 손이 먼저 잡히는 것 방지. 자르지는 않는다(낮은 제스처 보존) | hand_select `_acquire_tracked_hand` |
| **인계(takeover)** | 추적 손이 **연속으로 놀면**(takeover_idle_sec) 제스처하는 손에 정체성을 넘긴다 — 종전엔 한번 잡힌 손을 2초 소실 전엔 안 놓아 배 앞 쉬는 손에 고정됐다 (2026-08-03) | hand_select `_is_tracked_idle` |
| **거리 자(尺)** | 판정 임계를 픽셀이 아니라 "어깨너비 배수"로 — 카메라 거리가 달라져도 같은 동작 = 같은 판정 | hand_select `hand_scale_ratio` |
| **손 모양 래치** | 판별 깜빡임 방지 상태기 — 저속에서 고정, 이동 중 동결, 연속 확인 시에만 전환 | gesture_filter `_update_shape_latch` |
| **첫 선(first line)** | 원점을 떠나는 첫 이동 벡터로 방향 확정 — 사람마다 다른 궤적 스타일 흡수 | gesture_filter `_SwipeTracker._update_first_line` |
| **들어올리기 게이트** | 팔 드는 준비 동작이 "위 쓸기"로 오발되지 않게 — 휴식 존(어깨선 아래) 직후 위 방향 무시 | gesture_filter `_stamp_rest_zone`, `_is_arm_raise` |
| **복귀 삼킴** | 쓸고 되돌리는 팔이 반대 방향으로 오발되지 않게 — 직전 획 끝에서 시작한 반대 획 무시 | gesture_filter `_set_swallow` 계열 |
| **탭 클릭** | 한 손가락 제자리에서 검지 까딱 2회 = click — **검지 비율의 일시적 하강**(20%)으로 읽는다 (2026-08-03 교체: 주먹 판별로는 안 잡혔습니다) | gesture_filter `_update_tap_click` |
| **쥐기 선택** | 손 펼침 → 주먹 **1회 + 그 자리 정지**(dwell_sec) = select. 정지 조건이 핵심이다 — 없으면 주먹을 만드는 순간 select가 나가 명령 3종이 매번 오발을 단다 (2026-08-04 2회→1회) | gesture_filter `_update_grab_select`, `_resolve_grab_dwell` |
| **아래 쓸기 한계** | down·temp_*_bottom은 **팔 내리는 동작과 구분 불가** — 위치·거리 두 축으로 실측했고 둘 다 겹쳤습니다. 오발을 감수하기로 결정(2026-08-04) | 시나리오 22가 이 결정을 명시 |
| **ROI 줌** | 원거리에서 앵커 주변만 잘라 손 추론 — 먼 손도 모델 입력에서 크게 | realtime_loop `resolve_roi_box` |
| **어깨선 추정** | 휴식 존을 화면이 아니라 몸 기준으로 — 카메라 거치 각도와 무관 | hand_select `shoulder_line_y_ratio` |

## 4. 이벤트 규격 (UI 계약 — 총 14종)

| 손 모양 | 좌 | 우 | 위 | 제자리 더블 탭 |
|---|---|---|---|---|
| 손 펼침 `(5)` | `left` | `right` | `up` | `down` |
| 주먹 `(F)` | `back` | `confirm` | `home` | `temp_fist_bottom` |
| 한 손가락 `(1)` | `temp_left` | `temp_right` | `temp_top` | `temp_bottom` |

**`select`는 쓸기가 아니다** — 손 펼침에서 주먹을 쥐고 **그 자리에 잠깐 머물면**
나간다 (2026-08-04: 2회 반복에서 1회+정지로). 쥐자마자 쓸면 명령으로 갈립니다.
판정은 gesture_filter `_update_grab_select`, 수치는 config `gestures.grab_select`.
`click`(한 손가락 제자리 더블 탭)은 위 표의 방향 칸과 별개입니다.

- 아래 방향은 전 모양 공통 "정의 없음"(무시) · 손 펼침의 위도 정의 없음.
  출력 형식은 config `event_output`
  (기본: 이벤트명 한 줄. 상세 규격 `GESTURE|이벤트|손|신뢰도|시각`은 format: text).
- 델파이 수신 코드·규격 상세: docs/델파이7_연동가이드.md

## 5. 자주 하는 작업 — 어디를 고치면 되나

| 하고 싶은 것 | 여는 곳 |
|---|---|
| **인식이 무디다/과민하다 (전반)** | **`py scripts\calibrate.py`** — 측정해서 자동 반영 (권장) |
| 연속 제스처가 느림 / 같은 동작이 두 번 나감 | config `gestures.cooldown_sec` (↓ 0.4까지 · ↑) |
| 쓸기 민감도(얼마나 움직여야 인식) | config `gestures.swipe.min_dist_x/y_shoulder`, `flick_*` |
| 손 모양 판별이 너무 엄격/느슨 | config `hand_select.hand_shape` (실측 근거 주석 참고) |
| 쉬는 손에 추적이 고정됨 / 추적이 두 손을 오감 | config `hand_select.takeover_idle_sec` (↓/↑) |
| 대기줄에 3명 이상 자주 겹침 | config `head_anchor.num_poses` (↑ — 비용 거의 없음) |
| 옆 사람 손이 잡힘 / 내 손이 잘림 | config `head_anchor.wrist_reach_shoulder_widths` (↓/↑) → 그래도 안 되면 `reach_shoulder_widths` |
| 위 쓸기가 안 먹힘 / 들어올리기 오발 | config `gestures.swipe.raise_guard_*` (어깨선은 이제 실측 — 추정 항목 없음) |
| 주먹 명령이 select를 달고 나옴 / select가 굼뜸 | config `gestures.grab_select.dwell_sec` (↑ / ↓) |
| 탭 클릭 감도 | config `gestures.tap_click` (창·반경) + gesture_filter `TAP_DIP_MAX_SEC` |
| select(폈다 쥐기)가 안 나감 / 무심코 튐 | config `gestures.grab_select.window_sec` (↑/↓), `repeat_count` |
| 원거리 인식 | config `hand_tracker.roi_zoom`, `min_detection_conf` |
| 카메라가 안 열림/느림 | config `camera` 절 (device_id·windows_backend·auto_select) |
| 새 이벤트(모양×방향) 추가 | hand_shape에 모양 규칙 → gesture_filter `EVENT_BY_SHAPE`에 매핑 → config `classes` → 델파이 분기문 |
| 새 전송 방식(소켓 등) | event_sender에 Sender 클래스 1개 추가 + config `event_output.mode` |
| 이벤트가 안 나올 때 원인 추적 | `cam on`으로 창 열고 계기판(SCALE/ARM/SWIPE/LATCH/TAP/GRAB) 확인 → logs/ 파일 |

**수정 원칙** (CLAUDE.md): 숫자는 config에만 · 실측과 이유는 날짜와 함께 주석으로 ·
수정 후 `py -m unittest discover tests`(250건)가 카메라 없이 돌아야 합니다.

## 6. 실행·연동 요약

```bat
:: 공식 실행 (델파이 연동 명령과 동일 — 시스템 파이썬, 2026-08-03 가상환경 제거)
py main.py

:: 실행 중 콘솔에 타이핑 (또는 델파이가 stdin 파이프로)
cam on      ← 카메라·계기판 창 열기
cam off     ← 창 닫기
quit        ← 엔진 종료
```

- 시선추적은 exe(파이썬 내장)라 환경 공유 없음 — 별개 프로세스 (설치가이드 B-1).
  main.py는 특정 환경·작업 디렉터리에 묶이지 않습니다.
- 시작 소요·병목은 로그에 찍힌다: `프로세스 기동 n초` → `시작 소요: 모델 n초 ·
  카메라 포함 총 n초` (카메라 오픈은 모델 로딩과 병렬).
