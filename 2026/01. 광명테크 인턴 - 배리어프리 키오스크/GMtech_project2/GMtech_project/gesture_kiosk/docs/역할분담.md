### 1-1. 다중 이용 환경 조작권 방어 (이 배포의 핵심 요구)

"대기줄의 다른 사람에게 조작권을 뺏기지 않을 것" — 4겹으로 방어한다.
상세 근거는 TODO.md 13~20차 항목.

| 방어층 | 역할 |
|---|---|
| 깊이 관문(절대·상대) | 뒷사람 **손**이 판정에 진입 불가 |
| 작동 거리 창 | 어깨 관측이 붕괴해도 사는 절대 하한 |
| 대기줄 이음 방어 | 앵커가 뒷사람으로 교대 불가 |
| 관측 중앙값 | 단발 붕괴 제거 |

핵심 원리: MediaPipe가 주는 **월드 좌표(미터)와 화면 좌표(px)의 비**가 곧
카메라~손 거리다(손 크기가 약분돼 사라진다). 2D 위치로는 원리적으로 못 가르는
"일렬 대기줄"을 거리로 가른다. 추가 모델·의존성 없음.

**배리어 프리 대응**: 체형별 고유 상수를 세션 중 학습해, 어깨가 넓은 사용자의
손이 잘리지 않으면서 하이재킹 방어는 더 엄격해지도록 했다(20차).
인계 대기 시간은 1.5초 → 5초 — 고령·장애인 사용자가 화면을 읽느라 멈추는
동안 대기줄에 틈이 열리지 않게.

## 2. 회사 확인·제공 필요 — 담당: 회사 (진행 전 대기)

기획서 9장 연동 항목. **이 배포 시나리오에서 우선순위가 높은 순.**

### 🔴 최우선 — 배리어 프리 요구사항 직결

- **№1 제스처 스펙 확정 · 양손 없는 사용자 대응**
  현재 조작 수단은 손 제스처 **단독**이다(손목·팔꿈치 폴백 제거됨).
  양손이 모두 없는 사용자는 **조작 수단이 없다.** 배리어 프리 키오스크로서
  UI 자동 순회(스캐닝) 등 대체 수단 도입 여부를 회사가 결정해야 한다.

- **№1-2 설치 배치·카메라 화각 확인**
  대기줄이 화각에 상시 잡히는 배치인지. 오늘 넣은 방어는 전부 이 조건을
  전제로 설계했다. 배치가 다르면 임계값 재검토가 필요하다.
  ▶ **운영 권고: 바닥 대기선을 사용 위치보다 1m 뒤에 표시.**
    설정값을 조이는 것보다 안전하고 확실하다.

### 🟡 통합 진행에 필요

- **№7 회사 키오스크 프로그램(UI) 파일 수령** — 수령 후 연동 작업 시작
- **№7 이벤트 규격 합의** — 현재 classes **14종**. UI 분기문에
  `up`·`down`·`temp_bottom`·`temp_fist_bottom` 추가 필요(델파이7_연동가이드 §3).
  ※`temp_` 5종은 **회사 정의 대기 중** — 이름은 코드 한 곳에서 바꾼다
- **№8 통합 범위 확정** — UI 통합까지인지 이벤트 출력까지인지
- **№13 시선추적 모듈과 카메라 공유 방식** — 윈도우에서 같은 카메라를 두

## 3. 설치 현장 작업 — 담당: 설치 담당자 (배포 전 **필수**)

개발 PC 기준값이 그대로 들어 있는 항목이 있다. **재보정 없이 배포하면
정당한 사용자가 거부될 수 있다.**

### 3-1. 작동 거리 재보정 (필수)

`configs/config.yaml` → `head_anchor.min_operating_depth_px` (현재 300)

1. 로그 레벨 INFO 상태로 엔진 실행
2. **실제 사용 위치**에 서서 손을 든다
3. 로그의 `깊이 관문 통과: 손 깊이 NNNpx`를 여러 번 읽어 **최솟값** 확인
4. 그 최솟값의 **0.75~0.8배**로 설정
5. 대기선 위치에 사람을 세워 `거부`가 찍히는지 확인

> ⚠ **휠체어 착석 상태로도 반드시 측정할 것.** 앉으면 카메라와의 거리·높이가
> 달라진다. 이 값이 너무 높으면 휠체어 사용자가 **통째로 거부된다** —
> 배리어 프리 키오스크로서 최악의 실패다.

### 3-2. 카메라 배치

- 창문·조명을 **등지지 않게** 배치(역광). 개발 환경 실측에서 배경이 사용자보다
  밝았고(근경 136 / 원경 163), 그 상태에서는 노출 기반 기법이 역효과다.

### 3-3. IR 카메라 전환 시 (예정)

전환하면 **전 항목 재확인**이 필요하다(TODO.md "IR 카메라 전환 시 전면 재확인").
최소한:
- `min_operating_depth_px` 재보정 (3-1 절차 반복)
- `camera.exposure.manual: true`로 켜고 노출을 낮춰가며 뒷사람이 어두워지는
  지점 탐색 — IR은 조명이 장치에 딸려오므로 **먼 사람이 광학적으로 어두워진다**
  (빛의 1/d² 감쇠). 소프트웨어 방어보다 근본적이다
- 손 검출률·모양 판별 재측정 (임계값이 전부 RGB 실측 기반)
