## 1. MediaPipe → OpenVINO 교체 검토, 그리고 기각

> "미디어파이프가 손 꺾는 움직임에 둔하다고 한다. 미디어파이프를 없애고
> OpenVINO로 재설계 가능할까"

**검토 결과 — 오히려 손해**

OpenVINO는 **모델을 빠르게 돌려 주는 도구**이지 손 인식 모델 자체가
아니다. 미디어파이프를 빼면 손 관절을 잡아 줄 모델을 따로 구해서
붙여야 하는데, 그러면 지금 잘되는 것까지 다시 만들어야 한다.
그리고 지금 병목은 속도가 아니라 **판정 로직**이었다.

**대신 한 것** — 유지 시간(`hold_sec`)을 낮춰 반응을 빠르게 했다.

## 2. 판정 방식 전면 개편

이 날 커밋 21건. 판정 기준이 여러 번 바뀌었다.

**핵심 전환** — **"이동으로 획득"에서 "자세로 획득"으로.**
움직여야 잡히는 게 아니라, 자세를 취하고 있으면 잡힌다.
자세끼리 경쟁시키고 **휴식 존**을 둬서 팔을 내린 상태는 아예 판정에서 뺀다.

**최종 배치**
```
위    → home
아래  → back
주먹  → select
OK    → confirm
```

## 3. 팔 추적이 옆 사람에게 튀던 문제

- 판정 중인 손이 있으면 **반대쪽 팔 기준점을 아예 없앰**
- 전완 기준에 **팔 길이 관문** — 팔 길이를 넘는 위치의 손목은 배제
  (옆 사람 손목에 끌려가는 걸 막는다)
- 포즈 쪽 팔목·손목 추적점 전면 제거

## 4. 손바닥 쪽 OK 가 안 잡히던 문제

손바닥을 카메라 쪽으로 향하면 엄지와 검지가 만든 고리가 납작해져 안 잡혔다.
**화면상(2D) 엄지·검지 맞닿음**을 따로 보는 경로를 추가해 구제했다.
