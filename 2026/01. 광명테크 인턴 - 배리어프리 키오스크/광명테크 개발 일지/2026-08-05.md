# 2026-08-05 (수) 개발일지

**오버레이(투명 화면) 방식을 도입한** 날. 이게 지금 헤드트래커의 형태다.

## 1. 오버레이 방식

**요청** — "빈 화면 말고 **뒤에 바탕화면이 보이게** 방향판만 띄울 수 없나"

이게 결정적이었다. 카메라 화면 안에서만 도는 프로그램이 아니라,
**바탕화면 위에 투명하게 얹혀서 실제 윈도우를 조작하는** 형태가 된다.
델파이 7 프로그램을 조작하려면 반드시 이 형태여야 한다.

- 배경 완전 투명, 방향판만 표시
- 전체 화면
- 커서 옆의 `finger` / `fist` 같은 영어 표시 제거
- 방향판은 반투명 흰색, 커서는 초록색

## 2. 커서 떨림

손 모드와 오버레이 양쪽에서 커서가 떨렸다. 수정했지만 **떨림 문제는
이후에도 계속 나온다** (8/13, 8/26).

## 3. 모드 전환이 멀리서 안 되던 문제

> "머리 흔들어서 모드 전환하는 게 키오스크 **가까이서 흔들어야** 잘 되더라"

멀리 있으면 얼굴이 작게 잡히고, 같은 각도로 흔들어도 화면상 움직인 픽셀이
작아진다. 그래서 기준에 못 미친다.

> **거리 때문에 기준을 못 넘는다** — 이 구조가 8/26 드래그 떨림의 원인과
> 정확히 같다. 그때는 반대로, 멀어서 잡음이 **커지는** 쪽이었다.

## 4. D-pad 작업 종료

> "회사에서 UI 없이, 방향판 없이 손동작 상하좌우로 하면 좋겠다고 한다"

헤드트래커로 넘어간다.
