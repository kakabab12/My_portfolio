## 2. 캘리브레이션이 아예 안 되던 문제

**증상** — 가만히 있어도 자동 재정렬이 영영 발동하지 않았습니다.

**원인** — 클릭이 일어나면 재정렬 대기 시간을 다시 세도록 만들어 뒀는데,
그 처리가 **모든 판정을 통째로 초기화**하고 있었습니다. 가만히 있으면 1.5초마다
응시 클릭이 나가고 → 그 클릭이 재정렬 시계를 0으로 되돌리는 무한 루프라
10초를 영영 못 채웁니다.

> 실측 로그: **27초 동안 응시 클릭 13번, 재정렬 0번**

덤으로 "한 번 누르면 커서가 반경을 벗어나야 다시 누름" 규칙까지 같이
지워져서 클릭이 계속 반복되고 있었습니다.

**고친 것** — 재정렬 시계만 콕 집어 되돌리는 처리를 따로 만들었습니다.

**교훈** — 고치려고 넣은 코드가 원인이었습니다. 초기화 범위가 너무 넓었습니다.

## 3. 캘리브레이션 방식 재설계

조작 중에 재정렬이 끼어들어 커서가 중앙으로 튀었습니다. 아이콘을 겨냥하려고
커서를 멈춰 두는 동작이 그대로 재정렬 조건이 되어버렸기 때문입니다.

- 자동 재정렬을 껐습니다
- 시작할 때 하는 캘리브레이션은 그대로 유지
- 정지 유예가 끝나는 시점에 지금 자세를 새 중심으로 확정

시작 안내 문구에 **"입은 다물어 주세요"**를 추가했습니다. 이 8초 동안 입 벌림의
평상시 기준선도 함께 잡기 때문에, 입이 벌어져 있으면 기준이 잘못 잡힙니다.

## 4. 프레임이 안 나오던 진짜 원인

**내 예전 진단이 틀렸습니다.** "다른 작업이 CPU를 쓸 때만 느려진다"고 적어뒀는데,
다시 측정해 보니 **다른 스레드가 놀고 있어도 항상 15~16ms**였습니다. GIL 문제도
아니었습니다.

진짜 원인은 키 입력 확인이 "1ms만 자자"고 요청하는데, 윈도우 기본 타이머
눈금이 약 15.6ms라 한 눈금을 통째로 자버리는 것이었습니다.

```
cv2.waitKey(1)   중앙 10.5ms / 최악 17.1ms
cv2.pollKey()    중앙  0.00ms / 최악  0.06ms
```

**고친 것**
- 키 확인을 기다리지 않는 방식으로 교체 → 사실상 공짜
- 화면 전체를 매번 지우던 것을 **커서가 지나간 자리만** 지우도록 변경
  (실측 6.9~13.1ms → 0.02ms)
- 그릴 내용이 지난번과 같으면 다시 그리지도, 다시 올리지도 않음
- 같은 프레임을 두 번 추론하던 낭비 제거

> **결과: 화면 한 장 19.8ms → 10.4ms**

**또 하나 틀렸던 것** — 8월 18일에 "프레임 개선" 목적으로 추론 해상도를
0.75배로 낮췄는데, 실제로 측정해 보니 **이득이 0**이었습니다. 줄이려고 내는 비용
(1.24ms)이 줄여서 버는 시간(1.10ms)보다 컸습니다. 1.0으로 되돌리니 랜드마크
정밀도와 저조도 성능이 오히려 좋아졌습니다.

## 5. 커서가 밀려가던 문제 — 얼굴 기준 좌표계

**원인** — 기준점의 **화면상 절대 픽셀 위치**로 커서를 계산해서, "고개를
돌린 것"과 "몸이 통째로 움직인 것"을 구분하지 못했습니다.

**고친 것** — 화면이 아니라 **얼굴 자신을 기준**으로 위치를 재도록 바꿨습니다.
두 눈 중점을 원점, 두 눈 사이 거리를 자로 삼고, 고개 갸웃한 각도만큼
되돌립니다. 이러면 이동·크기·기울기가 전부 상쇄됩니다.

> 확인: 몸이 40px 움직여도 커서 이동 0

---

## 6. 작은 아이콘을 못 겨냥하던 문제

커서의 최소 이동 단위를 두 번 낮췄습니다.
- 도착으로 치는 문턱: 0.006 → 0.0035
- 다시 움직이기 시작하는 최소 거리: 0.01 → 0.006

0.01이면 약 15px이라 아이콘을 살짝 비껴 맞췄을 때 미세 조정이 안 됐습니다.

## 7. 종료할 때 커서가 안 돌아오던 문제

| 종료 방식 | 대응 |
|---|---|
| 예외로 죽음 / sys.exit | atexit |
| Ctrl+C | SIGINT |
| 콘솔 X 버튼, 로그오프, 종료 | SetConsoleCtrlHandler |
| taskkill /F | **못 막음** |

`taskkill /F`는 어떤 프로그램도 정리 코드를 못 돌립니다. 그래서 **시작할 때
무조건 한 번 복구**하도록 보완했다 — 그렇게 죽어서 화살표가 사라졌어도
다시 실행하는 순간 돌아옵니다.
