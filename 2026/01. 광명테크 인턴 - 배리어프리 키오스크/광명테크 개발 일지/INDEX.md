## 되풀이된 문제 세 가지

한 번에 안 끝나고 여러 번 다시 나온 것들.

**① 조작자 특정 (뒷사람·옆사람)**
7/20 얼굴 잠금 시도 후 되돌림 → 7/21 도달 거리 게이트 → 7/26 요청 →
8/4 착수 → 8/6 팔 길이 관문 → 8/7 블러 → 8/11 마무리 → 8/18 헤드트래커 이식
→ 8/21 깊이 추정으로 근본 해결 시도
**뿌리** 깊이 센서가 없어 크기로만 거리를 짐작해야 한다.

**② 커서 떨림**
8/5 → 8/13 → 8/26
**뿌리** 커서 위치를 두 눈 사이 거리로 나눠 정하기 때문에,
**멀수록 같은 잡음이 커서를 더 크게 흔든다.** (8/26에 측정으로 확인)

**③ 얼굴 동작 선정**
눈썹 올리기(7/18) · 입 오므리기(7/19) · 볼 부풀리기(7/21) ·
코 찡그리기(7/21) · 입 오므리기 재폐기(7/30) — 전부 폐기.
**남은 것** 입 벌리기 / 눈 감기 / 응시.
**뿌리** 변화 폭이 작고 사람마다 편차가 커서 하나의 기준선으로
판정할 수 없다.
