# 2026-07-30 (목) 개발일지

**손 제스처와 헤드트래커를 하나로 합친** 날. 화면 비율도 키오스크에 맞췄다.

---

## 1. 두 프로젝트 통합

기존 손 제스처는 그대로 두고, **머리를 좌우로 흔들면 헤드트래커 모드로
전환**되게 만들었다. 아이트래커는 뺐다.

## 2. 화면 비율을 세로로

키오스크 화면이 세로형이라 카메라 비율을 **9:16 세로**로 바꿨다.

## 3. 함수 이름 확정

```
코끝 위치        →  cursor
입 벌리기 / 1.5초 응시  →  select
눈 감기          →  home
입 오므리기      →  calibration
```

## 4. 입 오므리기 폐기 — 다시

**입술을 오므리지 않아도 오므렸다고 뜨는** 오탐이 너무 컸다.
수치 조정으로도 안 잡혀서, **5초 동안 응시하면 재정렬되는** 방식으로 바꿨다.

> 입 오므리기는 7/19에 이어 두 번째 폐기다. 입은 벌리는 동작 하나만
> 남기는 게 맞다는 결론.

## 5. 수직 감도 상향

> "고개를 완전히 숙여야 커서가 맨 밑으로 간다"

세로 감도만 두 차례 올렸다.
**이 조정은 8/13, 8/24, 8/26에도 반복된다** — 세로는 사람이 고개를
움직일 수 있는 각도 자체가 좌우보다 좁아서, 늘 좌우보다 더 키워 줘야 한다.

## 6. 남은 질문

> "헤드트래커 커서가 델파이 7에 적용될까"

카메라 창 안의 커서가 아니라 **실제 윈도우 마우스를 움직여야** 델파이
프로그램을 조작할 수 있다. 이 질문의 답이 **8/13의 실제 마우스 제어**다.
