## 1. 델파이 7 설치와 연동 시험

델파이 7(7.2)을 설치하고 UI를 띄워 **제스처로 실제 조작이 되는지**를 확인했다.

**한글이 깨졌다**
```
쌍문듸엡>>?
```
델파이 7은 유니코드 이전 세대라 한글 표시에 별도 처리가 필요하다.
여러 번 시도했고 재부팅까지 했지만 이 날 안에 완전히 해결되진 않았다.

## 2. 아이트래킹의 한계 확인

| 증상 | |
|---|---|
| 좌우 | 바라보는 방향 그대로 잘 인식됨 |
| **상하** | **거의 안 움직임** |
| 커서 | **와들와들 떨림** |

눈은 위아래로 움직이는 폭 자체가 좌우보다 훨씬 작다.
이 한계가 나중에 **아이트래킹 폐기 결정**(8/4)의 근거가 된다.

## 3. 제스처 혼동

**주먹 쥔 것과 손가락 하나 편 것을 헷갈려한다.**
이 문제는 8월 초까지 계속 재발한다.

## 4. 특허 조사

세미나 지적사항에 따라 손 제스처·헤드트래커·터치·카메라 관련 특허를
전부 조사해 표로 정리했다.

## 5. 함수 이름 규격 정리

| 기능 | 동작 | 함수 이름 |
|---|---|---|
| 포인터 이동 | 코끝 위치 추적 | (연속값이라 이 날 미정) |
| 선택 / 확인 | 입 벌리기 또는 1.5초 응시 | `ok` |
| 처음으로 | 양 눈 감고 0.6초 | `home` |

이 날 처음 적었다. 결국 `cursor`로 정해진다 (7/30).
