1. 핵심 기능 요약
## 시스템 업데이트 (Update All)

winget(프로그램), pip(파이썬), wsl(리눅스 서브시스템), UsoClient(윈도우 업데이트) 등의 핵심 명령어를 연달아 호출하여 시스템 전반의 소프트웨어를 최신 상태로 유지합니다.

## 시스템 청소 (Clean + Boost)

ipconfig /flushdns(네트워크 찌꺼기), del %TEMP%(임시 파일), dism(시스템 이미지 정리 및 복구), sfc(시스템 파일 무결성 검사), defrag(디스크 조각 모음)를 차례대로 실행하여 윈도우를 최적화합니다.

## 프로세스 초기화 (Game Mode)

taskkill 명령어를 이용해 리소스를 많이 차지하는 브라우저, 메신저, 게임 런처, 오피스 프로그램들을 백그라운드에서 일괄 강제 종료합니다. 이후 탐색기(explorer.exe)를 재시작하여 낭비되는 메모리를 즉시 반환받습니다.

## 인터넷 핑 테스트 (Ping Check)

구글(8.8.8.8)과 클라우드플레어(1.1.1.1)의 글로벌 퍼블릭 DNS 서버로 각각 5회씩 핑(Ping) 테스트를 수행하여 현재 네트워크의 지연 시간과 패킷 손실률을 진단합니다.

## PC 정보 확인 (My Info)

wmic(CPU, GPU), powershell(RAM 계산), ipconfig(내부 IP), curl ifconfig.me(외부 공인 IP) 명령어를 활용해 내 PC의 하드웨어 사양과 네트워크 주소를 터미널에 즉각 출력합니다.

2. 코드 구조 및 기술적 특징
## 자동 관리자 권한 획득 (fltmc 트릭)

fltmc 명령어는 관리자 권한이 없을 때 에러를 냅니다. 이 원리를 이용해 스크립트 실행 시 권한을 스스로 체크하고, 권한이 없다면 powershell Start-Process ... -Verb RunAs를 호출해 관리자 권한 UAC 창을 띄운 뒤 재실행하도록 아주 똑똑하게 설계되었습니다.

## 터미널 UI 세팅

chcp 65001: 터미널 인코딩을 UTF-8로 변경해 한글 깨짐을 방지했습니다.

color 0b: 검은 바탕에 하늘색 글씨를 적용해 해커/전문가용 툴의 느낌을 살렸습니다.

mode con: 실행 시 터미널 창 크기를 가로 110, 세로 40으로 고정하여 아스키 아트(ASCII Art)와 메뉴가 깨지지 않게 방어했습니다.

## 윈도우 숨겨진 내부 명령어 활용

UsoClient: 사용자에게 윈도우 설정 창을 띄우지 않고 백그라운드에서 조용히 윈도우 업데이트 스캔과 설치를 강제하는 강력한 명령어입니다.

## 안전장치 (사용자 동의 로직)

작업 중인 데이터가 날아갈 위험이 있는 프로세스 강제 종료(게임 모드) 기능에서는 set /p confirm=을 사용해 사전에 진행 여부(Y/N)를 묻는 안전장치를 두었습니다.
