## 유튜브 파트너 프로그램 — 반복/대량생산 콘텐츠 정책

이 게임은 채팅 명령어(tnt/fast/slow/big/재질변경), 신규 구독자 MegaTNT, 후원 티어별 이펙트가 실제로 화면에 반영되는 진짜 상호작용 콘텐츠입니다. 다만 아래가 "켜져서 작동 중"이어야 정책상 안전합니다.

- [ ] `CHAT_CONTROL: true` + 올바른 API 키/채널ID/방송ID로 채팅 연동이 실제로 살아있는지 방송 화면에서 확인 (하단 커맨드 피드에 시청자 닉네임이 뜨는지)
- [ ] 방송 제목/썸네일을 며칠에 한 번씩 교체
- [ ] 방송 설명란에 참여 방법 안내 (댓글로 `tnt`, `fast`, `slow`, `big`, 곡괭이 재질 이름을 치면 반영된다는 설명)
- [ ] 주기적으로 채팅에 직접 답하거나 개입 — 100% 무인 자동화보다 정책 리스크가 낮음
- [ ] 유튜브 스튜디오 "정책" 탭을 주 1회 확인해 경고/제한 여부 점검
