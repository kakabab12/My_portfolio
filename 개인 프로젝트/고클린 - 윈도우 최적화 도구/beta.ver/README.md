# SYSTEM CLEANER — 윈도우 최적화 도구

고클린(GoClean)을 참고해 만든 윈도우 최적화 도구입니다.
[alpha.ver](../alpha.ver/alpha_test1.py) 단일 파일을 패키지 구조로 다시 만든 **BETA 1.0**입니다.

![작동 모습](demo/demo.gif)

---

## 설치 / 실행

**exe로 바로 쓰기** — 파이썬 설치 필요 없음, 13 MB 단일 파일

1. 이 폴더의 [`SystemCleaner.exe`](SystemCleaner.exe)를 누르고 오른쪽 위 **다운로드(↓)** 버튼으로 받습니다.
2. 받은 파일을 더블클릭합니다.

**소스로 실행**

```bash
pip install -r requirements.txt
python run.py
```

### 처음 실행할 때 나오는 경고

코드 서명 인증서가 없는 개인 제작 프로그램이라, 처음 받은 PC에서는 윈도우가 경고를 띄울 수 있습니다.
악성코드라서가 아니라 **"아직 많이 받아진 적 없는 서명 없는 프로그램"** 이라서 나오는 경고입니다.

**① 브라우저 다운로드 경고** (Edge / Chrome)

"일반적으로 다운로드되지 않는 파일" 이라고 나오면

- **Edge** — 다운로드 목록에서 **`…` → 유지**. 한 번 더 물으면 **자세히 표시 → 그래도 유지**
- **Chrome** — **유지**

**② SmartScreen — "Windows의 PC 보호" 파란 창**

| 순서 | 화면 | 누를 것 |
|---|---|---|
| 1 | "Microsoft Defender SmartScreen에서 인식할 수 없는 앱의 시작을 차단했습니다." 아래에 **[실행 안 함]** 버튼만 보임 | 본문 아래 파란 글씨 **추가 정보** |
| 2 | `게시자: 알 수 없는 게시자`가 표시되고 **[실행]** 버튼이 새로 생김 | **[실행]** |

> **경고 없이 실행하려면** — 받은 파일을 오른쪽 클릭 → **속성** → 일반 탭 아래쪽 **차단 해제** 체크 → **확인**.
> 인터넷에서 받았다는 표시가 지워져서 SmartScreen이 묻지 않습니다.

**③ UAC — "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?"**

| 선택 | 결과 |
|---|---|
| **예** | 모든 기능 사용 (사이드바 버전 옆에 `관리자` 표시) |
| **아니요** | 앱은 그대로 열리고 청소·서비스 변경처럼 권한이 필요한 기능만 잠김 (`권한 제한` 표시) |

오류가 나면 `%APPDATA%\SystemCleaner\logs\error_YYYYMM.log`에 기록됩니다.

## 설계 원칙

**1. 삭제 전에 먼저 보여준다**
청소는 검사 → 결과 표 → `1.8 GB 를 삭제합니다` 확인 → 실행 순서입니다.
파일을 지울 때는 영구 삭제 대신 **휴지통**으로 보냅니다.

**2. 되돌릴 수 있게 만든다**
시작 프로그램 '사용 안 함'은 항목을 지우지 않고 윈도우가 실제로 쓰는
`Explorer\StartupApproved` 플래그만 바꿉니다(작업 관리자와 같은 방식).
삭제·서비스 변경 전에는 `%APPDATA%\SystemCleaner\backup\`에 JSON 백업을 남기고,
바꾼 내용은 `logs\audit_YYYYMM.log`에 기록합니다.
위험한 작업 전에는 시스템 복원 지점을 만듭니다(설정에서 끌 수 있음).

**3. 위험한 건 기본으로 꺼둔다**
휴지통 비우기, winsock 초기화, Prefetch 삭제, 게임 모드에서 오피스 종료는
모두 기본 OFF입니다. ⚙ 설정에서 켜야 동작합니다.

**4. 성공했다고 거짓말하지 않는다**
모든 외부 명령은 종료 코드를 확인해 성공/실패/시간 초과를 구분합니다.
실패하면 `FINISHED WITH ERRORS`와 함께 사유를 남깁니다.

**5. 멈추지 않는다**
명령마다 타임아웃이 있고, `CANCEL` 버튼 또는 `ESC`로 실행 중인 자식 프로세스까지 종료합니다.
UI 갱신은 전부 `app.ui()` → `after(0, ...)` 한 곳을 거칩니다(tkinter는 스레드 세이프하지 않음).

## 테스트

```bash
python tests/smoke_test.py
```

```bash
SystemCleaner.exe --selftest 보고서.txt
```

검사 내용은 `system_cleaner/selftest.py` 한 곳에 있고, **소스와 빌드한 exe에서 똑같이** 돌립니다.
exe로 묶었을 때만 깨지는 것들(번들에서 빠진 테마 파일, 콘솔이 없어 사라지는 예외,
창 모드 exe의 subprocess 핸들 문제)을 잡으려고 테스트를 패키지 안에 뒀습니다.

삭제·프로세스 종료·설정 변경은 호출하지 않는 읽기 전용 검사이며 exe 기준 60개 항목을 봅니다 —
번들 구성, 외부 명령 실행, 승격 명령 구성, 15개 화면 생성, 목록 로딩, 정렬, 언어 전환,
읽기 전용 작업 실행, 취소, 그리고 **검사 중 오류 로그에 예외가 하나도 안 쌓였는지**.
직접 조작 점검에서 찾았던 오류(켜자마자 빈 화면, 처음 연 목록이 빔, 영문 모드에 남은 한글, 작업 스케줄러 항목 삭제, 언어 전환·설정 화면 멈춤 등)도 다시 생기지 않는지 함께 봅니다.

## 빌드

```bash
pyinstaller --noconfirm system_cleaner.spec
```

결과물은 `dist\SystemCleaner.exe`입니다.

- `uac_admin=False` — 매니페스트로 관리자 권한을 강제하면 UAC를 거절했을 때 앱이 아예 안 켜집니다.
  앱이 시작할 때 직접 승격을 요청하고, 거절하면 제한 모드로 엽니다.
- `upx=False` — UPX 압축은 백신 오탐을 크게 늘립니다.
- 버전 정보 포함 — 파일 속성에 제품명·버전이 보입니다. 버전 정보가 없는 서명 안 된 exe는 휴리스틱 검사에서 더 의심받습니다.
- Pillow 제외 — customtkinter가 선택적으로만 import 하고 이 앱은 쓰지 않아 용량만 늘립니다.
