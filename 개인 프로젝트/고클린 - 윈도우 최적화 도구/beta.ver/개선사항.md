## 1. 알파 버전이 이 PC에서 실제로 안 돌고 있던 것

### 1-1. `wmic` 제거 (가장 큰 문제)

`wmic.exe` 는 Windows 11 24H2 부터 OS에서 **기본 제거**되었습니다.
이 PC(Win11 Pro 10.0.26200)에서 `where wmic` 을 실행하면 아무것도 나오지 않습니다.

그런데 `get_cmd_output()` 이 예외를 통째로 삼키고 `""` 를 돌려주기 때문에
`내 PC 정보` 는 **에러 없이 빈칸만 출력**되고, GPU 제조사 감지는 항상 "Manual Search" 로
빠지고 있었습니다. 5개 기능 중 1.5개가 조용히 죽어 있던 상태입니다.

```python
# alpha : 프로세스를 6번 띄우고, 이 PC에서는 전부 빈 문자열
cpu = self.get_cmd_output("wmic cpu get name")...

# beta : PowerShell CIM 한 번으로 JSON 수집 (프로세스 1개)
$obj = [ordered]@{ cpu=...; board=...; bios=...; gpu=...; ram_type=...; os=... }
$obj | ConvertTo-Json -Compress
```

덤으로 BIOS 버전, RAM 구성(`16GB@4800MHz + 16GB@4800MHz`), 코어/스레드 수,
마지막 부팅 시각, 드라이브별 사용량까지 나옵니다.

### 1-2. 성공/실패 판정이 사실상 가짜였음

```python
# alpha
try:
    subprocess.run("winget upgrade --all ...", shell=True, ...)
    s1 = "Up to date"     # ← run() 은 실패해도 예외를 안 던진다
except: s1 = "Check Required"
```

`subprocess.run()` 은 종료 코드가 0이 아니어도 `check=True` 없이는 예외를 던지지 않습니다.
명령이 완전히 실패해도 리포트에는 항상 `Up to date` / `Deleted` / `Reset` 이 찍혔습니다.

beta 는 `Proc(rc, out, err, timed_out, not_found)` 를 돌려주는 `Runner` 로 바꿔
**리턴 코드를 실제로 확인**합니다. 명령어 자체가 없으면 `Not found` 로 구분합니다.

### 1-3. 관리자 승격이 이 경로에서 깨짐

```python
# alpha
ShellExecuteW(None, "runas", sys.executable, " ".join(sys.argv), None, 1)
```

`sys.argv` 를 공백으로 이어 붙이면 경로에 공백이 있을 때 인자가 쪼개집니다.
이 프로젝트 경로가 정확히 그런 경우입니다 — `...\바탕 화면\고클린\...`.
게다가 PyInstaller exe 로 빌드하면 `sys.executable` 이 exe 자신이라, exe 가 자기 경로를
자기 자신의 인자로 받는 이상한 실행이 됩니다.

beta 는 `subprocess.list2cmdline()` 으로 제대로 인용하고 frozen 여부를 구분합니다.
**UAC 를 취소해도 앱이 사라지지 않습니다.** alpha 는 `sys.exit()` 으로 조용히 종료돼서
사용자 입장에서는 "눌렀는데 아무 일도 안 일어남" 이었습니다.

### 1-4. 스레드 안전성

tkinter 는 스레드 세이프하지 않습니다. alpha 는 워커 스레드에서 `self.log()`,
`self.status_title.configure()`, `self.progressbar.start()` 를 직접 호출했습니다.
당장은 대부분 동작하지만 간헐적으로 멈추거나 죽는 전형적인 패턴입니다.

beta 는 UI 접근을 `app.ui(fn, *args)` → `after(0, ...)` 한 곳으로 모았습니다.

> 참고로 이 성질 때문에 테스트도 다시 짰습니다. `after()` 는 메인 스레드가
> `mainloop()` 안에 있을 때만 동작해서, `update()` 루프로 돌리는 테스트는
> 콜백을 전부 조용히 버립니다. 그래서 스모크 테스트는 실제 이벤트 루프 위에서
> 제너레이터로 단계를 진행하도록 만들었습니다.

## 2. 데이터가 날아갈 수 있던 부분

### 2-1. 게임 모드가 오피스/한글을 경고 없이 강제 종료

```python
# alpha : 버튼 누르는 순간 저장 안 한 문서가 그대로 날아감
targets = [..., "Hwp.exe", "EXCEL.EXE", "WINWORD.EXE", "POWERPNT.EXE"]
subprocess.check_output(f"taskkill /F /IM {exe} /T", ...)
```

beta:

1. `psutil` 로 **지금 실제로 떠 있는** 프로세스만 수집하고 앱별 개수·메모리를 보여줍니다.
2. 체크박스 목록으로 **무엇을 끌지 사용자가 고릅니다.**
3. `terminate()` → 6초 대기 → 그래도 살아있는 것만 `kill()`.
   저장 안 한 문서가 있으면 앱이 저장 프롬프트를 띄울 기회가 생깁니다.
4. 오피스·한글·VS Code 는 **기본 목록에서 제외**하고 설정에서 켤 수 있게 했습니다.

`len(targets)`(= 단순히 리스트 길이 19)를 "대상 앱" 으로 찍던 것도 실제 프로세스 수로
바꾸고, 종료 전/후 여유 메모리를 **실측**합니다.
alpha 의 `MEMORY : OPTIMIZED` 는 아무것도 측정하지 않은 고정 문자열이었습니다.

### 2-2. 청소 전 미리보기 + 확인

alpha 는 버튼을 누르는 순간 바로 삭제였습니다. beta 는
검사 → 결과 표 → `1.8 GB 를 삭제합니다` 확인 → 실행 순서입니다.

### 2-3. 위험한 작업은 기본 OFF

| 항목 | alpha | beta |
|---|---|---|
| `netsh winsock reset` | 항상 실행 | 기본 OFF (재부팅 필요 + VPN/프록시 초기화 경고) |
| 휴지통 비우기 | 없음 | 기본 OFF (영구 삭제 경고) |
| Prefetch 삭제 | 없음 | 기본 OFF (다음 부팅 느려짐) |
| 오피스 강제 종료 | 항상 실행 | 기본 OFF |

### 2-4. 삭제 경로 가드 + 휴지통

`purge_tree()` 는 `C:\`, `C:\Windows`, `C:\Users`, 홈 디렉터리 등을 **거부**합니다.
대상 폴더 자체는 남기고 안의 내용만 지우며, 사용 중인 파일은 조용히 건너뜁니다.
대용량/중복 파일 화면에서 지우는 파일은 영구 삭제가 아니라 **휴지통**(`SHFileOperationW`)으로 갑니다.

### 2-5. 되돌릴 수 있게

- 시작 프로그램 '사용 안 함' 은 항목을 지우지 않고 `Explorer\StartupApproved` 플래그만
  바꿉니다. 작업 관리자와 같은 방식이라 언제든 되돌릴 수 있습니다.
- 삭제·서비스 변경 전 `%APPDATA%\SystemCleaner\backup\*.json` 에 이전 상태를 저장합니다.
- 바꾼 내용은 `logs\audit_YYYYMM.log` 에 남습니다.
- 위험한 작업 전 시스템 복원 지점을 만듭니다(기본 ON, 설정에서 해제 가능).

### 2-6. 청소할 때 탐색기를 끄지 않음

alpha 는 `CLEAN & BOOST` 끝에 `taskkill /f /im explorer.exe` 를 실행해서
열려 있던 폴더 창이 전부 닫혔습니다. 청소와 무관해서 제거했습니다.

## 4. 기존 기능이 나아진 부분

### 4-1. 임시 파일 — 몇 GB 지웠는지 나옵니다

`del /s /q /f "%TEMP%\*.*"` 는 결과를 알 수 없고 하위 폴더도 남깁니다.
beta 는 파이썬으로 직접 순회하며 **바이트 단위로 집계**합니다.
대상도 8곳으로 늘렸습니다(임시 폴더, 크래시 덤프, 오류 보고, Windows 업데이트 캐시,
배달 최적화, 썸네일 캐시, 인터넷 임시 파일, Prefetch).

### 4-2. 디스크 최적화 — SSD와 HDD를 구분

alpha 의 `defrag /C /O` 는 **모든 볼륨**을 대상으로 돕니다.
이 PC에는 SSD 2개 + HDD 1개가 섞여 있습니다.
beta 는 `Get-PhysicalDisk` 의 `MediaType` 을 읽어 **SSD 는 `/L`(TRIM), HDD 만 `/D`(조각 모음)** 을 돌립니다.

### 4-3. 핑 — 언어 설정과 무관하게 동작

```python
# alpha : 영문/한글 요약 줄에만 의존, 실패하면 "Nonems" 출력
re.search(r'(평균|Average)\s*=\s*(\d+)ms', out)

# beta : TTL 이 있는 응답 줄만 골라 파싱 → 로케일 무관
for line in out.splitlines():
    if "TTL" not in line.upper(): continue
    m = re.search(r"[=<]\s*(\d+)\s*ms", line)
```

평균만 찍던 것을 **min / max / jitter / 패킷 손실률** 까지 계산합니다.

### 4-4. 멈추지 않는 UI

| | alpha | beta |
|---|---|---|
| 타임아웃 | 없음 (DISM/winget 이 멈추면 버튼이 영영 비활성) | 명령마다 설정 (DISM 30분, winget 30분 …) |
| 취소 | 불가 | `CANCEL` / `ESC` — 실행 중인 자식 프로세스까지 종료 |
| 진행률 | indeterminate(계속 흐르기만 함) | 단계별 실제 % + 경과 시간 |
| 실패 표시 | 항상 `JOB FINISHED` | `FINISHED WITH ERRORS` + 실패 사유 목록 |
| 목록 로딩 | — | 백그라운드 스레드에서 로딩(서비스 325개 조회 중에도 UI 가 살아 있음) |

### 4-5. 그 외

- **설정 저장**: `%APPDATA%\SystemCleaner\config.json`
- **로그 저장** 버튼: `문서\SystemCleaner\log_*.txt`
- **터미널 읽기 전용**: alpha 는 로그 창에 사용자가 타이핑할 수 있었습니다.
- **리포트 박스 정렬**: `"═" * (box_width - len(title))` 은 제목이 길면 음수가 되어
  테두리가 사라집니다. 한글 폭(전각 2칸)을 계산하는 `display_width()` 를 추가했습니다.
- **표 정렬**: `1.5 GB` 같은 표시 문자열이 아니라 실제 바이트로 정렬합니다.
- **`start` 셸 명령 제거**: `os.startfile()` 로 대체.
- **자리표시자 계좌번호 제거**: alpha 에는 `"3333-xx-xxxxxx"` 가 그대로 박혀 있었습니다.
  beta 는 `config.json` 값이 비어 있으면 후원 버튼 자체를 띄우지 않습니다.
- **콘솔 창 숨김**: 매번 `STARTUPINFO` 를 만들던 것을 `creationflags=CREATE_NO_WINDOW` 하나로.

## 6. 이번 버전에서 뺀 것

한때 **위협 점검(자동 실행 서명 검증 · hosts/프록시 변조 탐지 · 격리 보관함)** 화면을
만들었다가 제거했습니다.

기능 자체는 동작했지만, 검증용 테스트가 `%TEMP%` 에 **가짜 hosts 파일**(보안 사이트를
차단하는 내용)을 만들어 탐지 로직을 확인하는 방식이었고, Windows Defender 가 그 파일을
`SettingsModifier:Win32/PossibleHostsFileHijack` 으로 잡아 경고를 띄웠습니다.
실제 hosts 파일은 건드리지 않았고 임시 파일도 테스트 종료와 함께 지워졌지만,
최적화 도구가 백신 경고를 유발하는 구조는 배포판에 둘 이유가 없어 관련 모듈
(`threats.py`, `netconn.py`, `pages_security.py`)과 테스트를 전부 제거했습니다.
