1. 핵심 기능 요약
## 시스템 업데이트 (System Update)

winget과 pip를 이용해 설치된 소프트웨어와 파이썬 패키지 업데이트를 시도합니다.

Windows 업데이트와 MS Store 창을 자동으로 띄워줍니다.

[특징] wmic 명령어로 사용자의 그래픽카드 제조사(NVIDIA, AMD, Intel)를 자동 감지하여, 해당 제조사의 공식 드라이버 다운로드 웹사이트를 브라우저로 열어주는 똑똑한 기능이 포함되어 있습니다.

## 최적화 및 부스트 (Clean & Boost)

DNS 캐시 초기화(ipconfig /flushdns), 임시 폴더(Temp) 파일 강제 삭제, 시스템 이미지 정리(dism), 소켓 초기화(netsh winsock reset), 디스크 조각 모음(defrag) 등 Windows 내장 명령어를 총동원하여 시스템을 청소합니다.

## 게임 모드 (Game Mode)

게임 프레임에 영향을 줄 수 있는 무거운 백그라운드 프로그램들(크롬, 엣지, 카카오톡, 디스코드, 스팀, 오피스 등)의 리스트를 만들어 taskkill로 일괄 강제 종료합니다.

종료 후 Windows 탐색기(explorer.exe)를 재시작하여 메모리를 반환받습니다.

## 핑 테스트 (Ping Test)

안정적인 게임 환경을 위해 구글(8.8.8.8)과 클라우드플레어(1.1.1.1) DNS 서버로 핑을 보냅니다.

정규표현식(re)을 통해 평균 지연 시간(ms)을 추출하고, 응답 속도에 따라 '매우 좋음', '보통', '느림' 등으로 상태를 평가해 줍니다.

## 내 PC 정보 (My PC Info)

wmic와 powershell 명령어를 호출하여 CPU, 메인보드, GPU 이름과 RAM 총용량을 가져옵니다.

내부 IP(로컬)와 외부 IP(퍼블릭)를 스캔하여 터미널 창에 띄워줍니다.

2. 기술적 설계 및 코드 특징
## 관리자 권한 자동 획득 (is_admin)

시스템 파일 삭제나 네트워크 설정 변경(netsh)은 관리자 권한이 필수입니다. 코드가 실행될 때 ctypes.windll.shell32.IsUserAnAdmin()을 통해 권한을 확인하고, 없다면 UAC(사용자 계정 컨트롤) 창을 띄워 관리자 권한으로 재실행하도록 설계되었습니다.

## 멀티스레딩 적용 (threading)

명령 프롬프트(subprocess) 명령이 끝날 때까지 기다리면 GUI 프로그램이 "응답 없음" 상태가 되며 멈춥니다. 이를 방지하기 위해 모든 기능이 threading.Thread(target=task, daemon=True).start() 형태로 분리되어 백그라운드에서 안전하게 돌아갑니다.

## 세련된 다국어 UI (customtkinter & locales)

구식 tkinter 대신 customtkinter를 사용하여 다크 모드 기반의 모던한 UI를 구현했습니다.

사이드바에는 버튼을, 메인 영역에는 명령 프롬프트(CMD) 느낌이 나는 터미널 텍스트 박스를 배치했습니다.

딕셔너리(ui_locales, cmd_locales)를 만들어 [한글/ENG] 버튼 클릭 한 번으로 모든 버튼과 터미널 출력 언어가 실시간으로 전환되도록 완벽한 다국어(i18n) 처리를 해두었습니다.

## 팝업 및 클립보드 제어 (개발자 후원 기능)

ctk.CTkToplevel을 사용해 메인 창 위에 작은 팝업창을 띄우고, 후원 링크를 웹브라우저로 열거나(webbrowser.open), 카카오뱅크 계좌번호를 클립보드에 바로 복사해 주는(clipboard_append) 디테일한 편의 기능을 구현했습니다.
